# 休講登録の操作手順（コンピューターユース用）

帯広畜産大学の教務システム（WebPortal）で、指定した授業の休講を登録する手順。

- 元動画：同じフォルダの `休講手順.mp4`（約1分33秒）
- 確認日：2026-11-09
- 確認方法：動画の冒頭から終端までの画面遷移と、主要操作前後の拡大画像を確認。音声トラックは無音。
- 本書は動画を基にした操作記録。実システムでの再実行は行っていない。

## 1. 実行前にそろえる情報

次回の依頼内容から以下を確定する。動画に表示された科目・日付・休講理由は、そのまま流用しない。

| 項目 | 必要な内容 |
|---|---|
| 対象授業 | 開講年度・学期、科目名。候補が複数なら時間割番号で区別する |
| 休講対象 | 年月日、時限。複数日なら各日を明示する |
| 休講理由 | 実際に登録する文面 |
| 理由の公開設定 | 「公開」または「非公開」 |
| 変更範囲 | その1回のみか、基準日以降の全授業か |
| 有効期限 | 画面で選ぶ期限。動画では「休講日の当日まで」 |
| 補講有無 | 「未定」「有」「無」 |
| 追加内容 | 必要なら備考、学生へのメッセージ、事務への連絡、添付ファイル |

既に依頼で指定済みの事項は再確認しない。授業・日付・理由などを特定できない場合は、足りない項目だけ確認する。公開設定などは動画の値を無条件の既定値にしない。

## 2. 操作経路の概要

`Moodle → WebPortal → ログイン → 履修・成績情報 → 出欠管理 → 対象授業の「参照・編集」 → 対象日の「休講登録」 → 入力 → 確認画面へ → 登録する → 登録完了 → 閉じる`

## 3. 画面ごとの操作

### 3.1 WebPortal にログインする（動画 00:00～00:12）

1. Moodle のダッシュボードを開く。動画のURLは `https://moodle.obihiro.ac.jp/moodle3/my/`。
2. 右側の「帯広畜産大学 Links」にある **「WebPortal」** をクリックする。
3. 教務システムのログイン画面が表示されることを確認する。動画の遷移先は `https://gkm02.obihiro.ac.jp/Portal/Login.aspx`。
4. 利用者の認証手段でログインする。既にログイン済みなら次に進む。パスワードやワンタイムパスワードの値を本書・作業ログに記録しない。
5. トップページに「履修・成績情報」などのメニューが表示されることを確認する。

動画には認証操作の細部は記録されていない。認証が必要な場合は、その時点の画面に従う。

### 3.2 対象授業の出欠一覧を開く（動画 00:12～00:36）

1. 上部の **「履修・成績情報」** をクリックする。
2. 下に現れる **「出欠管理」** をクリックする。
3. 「出欠記録授業検索」の「授業科目一覧」が表示されたら、年度・学期のプルダウンを確認する。対象の年度・学期と異なれば切り替える。
4. 対象行の「開講年度」「開講学期」「時間割番号」「科目名」「時限」を照合する。
5. その行の右端、「出欠状況」列の **「参照・編集」** をクリックする。
6. 「出欠一覧」で、上部の科目情報が対象授業と一致していることを確認する。

動画では、メニュー付近にポインターを合わせるだけの場面もある。実際の操作経路は上記の「履修・成績情報」→「出欠管理」である。

### 3.3 対象日の休講登録を開く（動画 00:36～00:55）

1. 下へスクロールし、横長の出欠一覧の見出しを表示する。
2. 表には「授業回」「日付（個別設定）」「曜日」「時限」「備考」の行がある。必要に応じて **画面下部の横スクロールバーを右へ動かす**。
3. 対象の日付の列を探し、曜日・時限も照合する。年度をまたぐ場合は、月日だけで判断しない。
4. 対象列の「備考」行にある **「休講登録」** をクリックする。ボタンは「休講」「登録」の2行表示になる場合がある。
5. 別ウィンドウで **「休講登録」** 画面が開くので、そちらへ操作対象を切り替える。
6. ウィンドウ上部の科目名・時間割番号と、フォームの **「休講日」「時限」「授業時間」** を確認する。間違っていれば登録せず閉じ、対象列を選び直す。

**同じ列の下にある「編集」は出欠編集用で、休講登録とは別のボタン。青い日付リンクも、この動画で使用する入口ではない。**

科目の基本情報に表示される曜日と、個別の授業日の曜日が異なることがある。最終的な休講対象は、開いたフォームの年月日・曜日・時限と依頼内容を突き合わせて判断する。

### 3.4 休講内容を入力する（動画 00:55～01:10）

画面上部の進行表示が「編集」であることを確認する。

| 画面項目 | 操作・確認内容 | 動画での設定 |
|---|---|---|
| 休講日・時限・授業時間 | 対象日時が正しいか確認する | 選択した授業回の情報が表示される |
| 変更区分 | 1回のみなら「基準日のみ」。画面の説明では「基準日から」は基準日以降の全授業が対象 | 基準日のみ |
| 有効期限 | 依頼に応じて選ぶ | 休講日の「当日まで」 |
| 補講有無 | 「未定」「有」「無」から選ぶ | 未定 |
| 休講理由 | 依頼された文面を入力し、日本語の変換を確定する | 理由を入力（個別の文面は本書に転記しない） |
| 公開／非公開 | 休講理由のすぐ下で指定する | 公開 |
| 備考 | 必要な場合に入力する | 空欄 |
| 学生へのメッセージ | 依頼された文面がある場合に入力する | 空欄 |
| 事務への連絡 | 依頼された文面がある場合に入力する | 空欄 |
| 添付ファイル | 指定されたファイルがある場合に選択する。動画では3枠表示 | 添付なし |
| 休講の取り消し | 新規の休講登録では「取り消し」にチェックを入れない | 未選択 |

入力後、**ポップアップ側を下へスクロール**し、最下部の **「確認画面へ」** をクリックする。背面の出欠一覧をスクロールしないよう、操作対象を確認する。

### 3.5 内容を確認して登録する（動画 01:11～01:17）

1. 進行表示が **「内容の確認」** に変わり、入力内容が一覧になったことを確認する。
2. 科目名・時間割番号、休講日・時限・授業時間、変更区分、有効期限、補講有無、理由と公開設定、追加の文面・添付を照合する。
3. 修正があれば **「登録画面へ戻る」** をクリックして直す。
4. 依頼された登録内容と一致していれば、**「登録する」** を1回クリックする。

「確認画面へ」ではまだ登録は完了していない。「登録する」が確定操作であり、完了画面には確認メールが送信される旨が表示される。実行時は、休講登録の依頼範囲内で操作する。

### 3.6 完了を確認して閉じる（動画 01:18～01:32）

1. 進行表示が **「登録完了」** になったことを確認する。
2. 次のメッセージを確認する。

   > 休講情報の登録が完了しました。
   >
   > 確認のメールが送信されます。

3. **「閉じる」** をクリックし、元の出欠一覧へ戻る。
4. 必要に応じて元の一覧を再読み込みし、対象授業・日付の状態を確認する。再読み込みで送信の再実行を求められた場合は、そのまま再送しない。
5. 利用者へ、対象科目・休講日時・登録完了の確認結果を簡潔に報告する。

完了画面には「補講登録」もあるが、動画では使用せず「閉じる」を選んでいる。補講登録の具体的な手順はこの動画の範囲外。

**完了判定は登録完了メッセージを根拠にする。** 動画では、ポップアップを閉じた直後の一覧に「休講登録」ボタンが残っているため、ボタンの有無だけで失敗と判断して再登録しない。末尾では一覧の再読み込みが見られるが、再読み込み後の対象日欄の更新結果までは確認できない。メールの実際の受信・宛先も動画では確認されていない。

## 4. コンピューターユース時の判断基準

- 画面座標を固定せず、現在の画面のラベル・対象科目の行・対象日の列を読み取って操作する。
- 画面遷移ごとに表示を取り直す。読み込み中の白い画面や、直前の画面を根拠に連続クリックしない。
- 同名の「参照・編集」「休講登録」「編集」が多数ある。必ず対応する行・列を特定する。
- 休講登録画面が見えない場合は、開いた別ウィンドウ・タブ、ブラウザーのポップアップ通知を確認する。元のボタンを連打しない。
- 対象科目や日付が見つからない場合は、年度・学期、縦横スクロール、対象科目の選択を再確認する。近い日付で代用しない。
- 既に「休講」と表示されるなど動画と状態が異なる場合は、既存登録を確認し、重複登録を避ける。取り消し・訂正の具体的操作はこの動画では未確認。
- 入力エラーが出た場合は表示内容に従って該当項目を修正する。完了画面が確認できない場合は結果未確認として扱い、登録操作を繰り返す前に現在の状態を調べる。
- 公開リポジトリには、ログイン情報、個人名、学生の氏名・学籍番号・出欠情報、個別の連絡内容を保存しない。出欠一覧の未加工スクリーンショットも保存対象にしない。
