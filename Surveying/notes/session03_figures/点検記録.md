
## 内容上の注意と指示書との差異

1. **第XIII系の原点経度を訂正した。** 指示書の「東経144°」に対し、公式の原点は北緯44°・東経144°15′。図の点位置と注記は公式値を採用した。19系の経緯度は[国土地理院「平面直角座標系」](https://www.gsi.go.jp/LAW/heimencho)で照合した。海岸線は描かず、楕円と点だけで配置している。原点が適用区域の外に置かれる場合もあるため、楕円は区域を表さない。
2. 縮尺係数の指定式をそのまま描画した。±90 kmで約0.9999998、±130 kmで約1.0001082となるので、図の1.0000・1.0001には近似記号を添えた。指定の縦軸上限1.0002を超える両端の曲線は、プロット領域で切られる。
3. 真北方向角γは国土地理院の定義に合わせ、座標北から真北へ右回りを正とした。原点より東（Y > 0）で負、西（Y < 0）で正となり、方位角は `α = T − γ`。図は原点より西の点（γ > 0）の例として、真北を座標北の右（東）側、磁北を左（西）へ約9°傾けた。座標北→OPを方向角T、真北→OPを方位角α、座標北→真北を真北方向角γの弧で示し、角度は説明用に拡大した。旧版の左回り正・加算式と「符号は定義による」の注記は削除した。
4. 基準面への補正図は指示書の `R + H` と式を保持した。標高と楕円体高を厳密に混同しないよう「球面近似」「ここでは H を基準面からの高さとみなす」と図内に明記した。
5. 逆算図では軸上を別判定とし、同一点では方向角が定まらない旨を補足した。
