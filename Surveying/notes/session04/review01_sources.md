# 第4回「角測量」調査メモ01：方向法・正反観測・高度定数

調査日：2026-10-27

## 1. 倍角・較差・倍角差・観測差

同じ視準方向について、対回 (k) の正位・反位から得た観測結果（反位は180°を加減して正位と同じ角の範囲へ直した値）を (r_k,l_k) とする。

\[
D_k=r_k+l_k \quad（倍角）
\]

\[
C_k=r_k-l_k \quad（較差）
\]

複数対回について、

\[
\Delta_D=\max_k D_k-\min_k D_k \quad（倍角差）
\]

\[
\Delta_C=\max_k C_k-\min_k C_k \quad（観測差）
\]

とする。実際の手簿では度・分が相殺されるよう整理されるため、秒欄だけを加減する例が多い。名称が紛らわしいが、**較差は1対回内の正−反、観測差は複数対回の較差の最大−最小**である。

- 国土地理院「作業規程の準則」：方向観測法を採用し、等級別に倍角差・観測差を点検する一次資料。現行資料入口：<https://www.gsi.go.jp/gijyutukanri/gijyutukanri41018>
- 国土地理院「作業規程の準則 付録1 測量機器検定基準」：水平角の検定項目を倍角差・観測差・セット間較差として明記。<https://web1.gsi.go.jp/common/000268569.pdf>
- 国土地理院の仕様書例：水平角は方向観測法、点検値として倍角差15秒・観測差8秒を明記。<https://www.gsi.go.jp/common/000252667.pdf>
- 定義式を明記した補助教材（測量士補教材）：<https://www.kinomise.com/sokuryo/shiho/jyuuyou/kijyun/kijyun08-houkou.pdf>

### 採用推奨

授業では (r,l) を「生の水平目盛」ではなく、**零方向との差を取り、反位を同じ周回へ直した観測結果**と明記する。倍角差・観測差は絶対的な正確さではなく、対回間の再現性を点検する量である。許容値は講義独自値と混ぜず、扱う測量等級・規程を併記する。

## 2. 正反平均で消える（一次で相殺される）器械誤差

同じ目標を正位（Face I）と反位（Face II）で測り、反位を同じ角の表現へ直して平均すると、望遠鏡反転で符号が逆になる誤差は一次近似で相殺される。

- 水平視準軸誤差（視準線が横軸に直交しない）
- 横軸誤差（横軸が鉛直軸に直交しない）
- 鉛直目盛の指標誤差（鉛直角・天頂角の高度定数ずれ）

Nottingham大学の研究資料は、水平視準軸誤差、横軸誤差、鉛直円指標誤差を説明し、Face Left/Face Right の平均で相殺されると明記している：<https://eprints.nottingham.ac.uk/14491/1/246414.pdf>

メーカー資料では、Leica TC600/TC800取扱説明書が「水平視線なら鉛直円は90°を読むべきで、そのずれが vertical index error」と定義する：<https://naic.nrao.edu/~phil/hardware/theodolites/LeicaTC800_manual.pdf>。現行Leica X-PADもFace I/Face IIを測って平均する機能を説明している：<https://xpaddocs.leica-geosystems.com/x-pad/latest/user-manual/survey-tps/tps-measure-mode>

### 消えない／正反だけでは保証できないもの

- 鉛直軸の傾き（整準不良）：望遠鏡反転でも鉛直軸そのものは同じ
- 求心誤差、目標の偏心、視準・読定の偶然誤差
- 大気屈折、陽炎、三脚や地盤の時間変化
- 水平目盛の分画誤差：対回ごとに初期目盛を変えて分散させる対象

### 採用推奨

「正反ですべての誤差が消える」は不採用。「**望遠鏡反転で符号が反転する主要な器械誤差を相殺する。整準・求心・大気・視準誤差は残る**」と説明する。

## 3. 鉛直角の高度定数

天頂角方式（天頂0°）で、同じ目標への正位読定を (Z_L)、反位読定を (Z_R) とする。理想条件は、

\[
Z_L+Z_R=360^\circ
\]

である。方向 (j) の高度定数のずれを、

\[
K_j=Z_{Lj}+Z_{Rj}-360^\circ
\]

と置ける。指標誤差を両面読定へ同符号で入る (i) と定義すれば (K_j=2i)。正反から補正した天頂角は、

\[
Z_j=\frac{Z_{Lj}+(360^\circ-Z_{Rj})}{2}
=\frac{Z_{Lj}-Z_{Rj}+360^\circ}{2}
\]

となる。複数方向を観測したときの**高度定数の較差**は、

\[
\Delta_K=\max_j K_j-\min_j K_j
\]

で点検する。なお、教材・機種によっては (Z_L+Z_R) 自体を「高度定数」と呼ぶため、「360°との差」なのか「和」なのかを式で宣言する必要がある。

- 国土地理院「測量機器検定基準」：鉛直角を3方向（+30°, 0°, −30°）で1対回観測し、「高度定数の較差」を級別に規定。<https://web1.gsi.go.jp/common/000268569.pdf>
- 国土地理院系の点検要領（国土調査）：鉛直角点検を「定数差」として級別制限値を掲載。<https://www.chiseki.go.jp/info/pdf/tenkenyouryou.pdf>
- Leica取扱説明書：水平視線の90°からのずれを vertical index error と定義。<https://naic.nrao.edu/~phil/hardware/theodolites/LeicaTC800_manual.pdf>

### 採用推奨

スライドではまず (Z_L+Z_R=360°) を図示し、個々の方向の (K_j) と、方向間の 「高度定数の較差」 ΔK を別ラベルにする。高度角 α（水平0°、上向き正）への変換は、補正済み天頂角について α=90°−Z とする。機器表示が高度角方式の場合は符号・正反式が変わるため、天頂角方式との混在を避ける。
