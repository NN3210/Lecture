# 第4回「角測量」定義監査05：方向法・高度定数

調査日：2026-10-27

## 結論（`review01_sources.md` の監査）

1. **方向法の「較差」は、生の円周読定値について反−正を180°換算した差ではない。** 各望遠鏡位置で零方向の読定値を引いて得る「結果」（零方向を0°とした方向値）を用い、同一対回・同一視準点について **正の結果−反の結果** とする（観測順が反→正でも、符号は正−反）。
2. **観測差は、同一対回内の値の range ではない。** 同一視準点について、各対回で得た較差の **対回間の最大値−最小値** である。
3. **倍角差は、帰零方向の閉合（帰零差）や「帰零倍角」の対回間 range ではない。** 同一視準点について、各対回の正・反の「結果」の秒値を桁をそろえて加えた倍角を作り、その **対回間の最大値−最小値** とする。零方向は各正反列で結果を0°にする基準であり、別項目の帰零差と混同しない。
4. `review01_sources.md` の方向法の式は、そこでいう \(r_k,l_k\) が**生読定値でなく零方向差引後の「結果」**である限り妥当。ただし式の直前にこの条件を太字で固定すべきである。
5. **高度定数は全差** \(K=r+\ell-360^\circ\) である。零点（指標）誤差を半分で表す流儀なら \(i=K/2\)（符号規約によっては \(-K/2\)）だが、公共測量の「高度定数の較差」に \(i\) を入れてはならない。`review01_sources.md` の \(K=r+\ell-360^\circ\) と \(\max K-\min K\) は正しい一方、「\(K=2i\)」は符号規約依存と注記する必要がある。

## 一次資料に近い記載例による水平角の確認

令和2年度測量士補試験 No.5 の観測手簿は、「観測角」と「結果」を別欄にする。0°輪郭では、零方向303の正読定が 0°00′20″、目標(1)が 97°46′19″なので、正の結果は

\[
R_1=97^\circ46'19''-0^\circ00'20''=97^\circ45'59''.
\]

反では目標(1) 277°46′26″、零方向303 180°00′28″なので、

\[
L_1=277^\circ46'26''-180^\circ00'28''=97^\circ45'58''.
\]

したがって較差は \(C_1=R_1-L_1=+1''\)、倍角は秒位をそろえて \(D_1=59''+58''=117''\)。90°輪郭では結果が反 97°45′59″、正 97°46′02″なので \(C_2=+3''\)、\(D_2=59''+62''=121''\)。よって

\[
\text{倍角差}=121''-117''=4'',\qquad
\text{観測差}=3''-1''=2''.
\]

この表は、(a) 零方向を差し引いてから正反を比較すること、(b) 較差は正−反であること、(c) 観測差・倍角差はいずれも対回間 range であることを同時に示す。参照：令和2年度測量士補試験 No.5、表5（1頁）
https://www.kinomise.com/sokuryo/shiho/ho-mtoa/r02ho/r02ho-5m.pdf
国土地理院の過去問公開ページ（現在の掲載は過去5年分）：
https://www.gsi.go.jp/LAW/SHIKEN/past.html

補助教材として、「方向観測法による水平角の計算」p.3も、倍角＝正結果＋反結果、較差＝正結果−反結果、倍角差・観測差＝それぞれの最大−最小と明記する：
https://www.kinomise.com/sokuryo/shiho/jyuuyou/kijyun/kijyun08-houkou.pdf

## 高度定数：K と指標誤差を分離する

天頂角表示で同一目標を正 \(r\)、反 \(\ell\) で読むと理想は \(r+\ell=360^\circ\)。公共測量の用語解説は明確に、

\[
K=r+\ell-360^\circ
\]

を「高度定数」、2方向以上の \(K\) の最大値−最小値を「高度定数の較差」と定義する（『測量』2022年7月、p.59、本文および図1）。
https://www.jsurvey.jp/20220705P59-2.pdf

例：目標Aで \(r_A=65^\circ41'50''\)、\(\ell_A=294^\circ18'10''\) なら \(K_A=0''\)。目標Bで \(r_B=47^\circ26'40''\)、\(\ell_B=312^\circ33'30''\) なら \(K_B=+10''\)。したがって高度定数の較差は \(10''-0''=10''\) であり、半分の5″ではない。

なお、補正済み天頂角は

\[
Z=\frac{r+(360^\circ-\ell)}{2}
  =r-\frac{K}{2}.
\]

この式に現れる \(K/2\) は片面読定に対する補正量（指標誤差の大きさ）であり、野帳の「高度定数」そのものではない。資料によって指標誤差を \(c=(360^\circ-r-\ell)/2=-K/2\) と定義する場合があるため、**記号 \(i\) の符号は定義式なしに断言しない**。一方、公共測量の点検量 \(K\) とその較差は上記全差で一意である。

国土地理院「測量機器検定基準」p.2（PDFページ2）は、鉛直角を +30°、0°、−30°の3方向で各1対回観測し、「高度定数の較差」で判定する手順と許容値（1級7″、2級30″、3級60″）を示す：
https://www.gsi.go.jp/common/000268569.pdf

## HTML / PPT に採用できる厳密な手順

### 水平角（各対回 k・各非零方向 j）

1. 正・反を独立に零方向差引きする：\(R_{kj}=\operatorname{wrap}_{360}(H^r_{kj}-H^r_{k0})\)、\(L_{kj}=\operatorname{wrap}_{360}(H^\ell_{kj}-H^\ell_{k0})\)。
2. 360°境界をまたぐ場合は、\(R_{kj}\) と \(L_{kj}\) が同じ角の枝になるよう±360°を加減して桁をそろえる。
3. 較差：\(C_{kj}=R_{kj}-L_{kj}\)。倍角：\(D_{kj}=R_{kj}+L_{kj}\)（実務野帳では共通の度・分を除き秒値で記帳することが多い）。
4. 視準点 j ごとに、\(\Delta C_j=\max_k C_{kj}-\min_k C_{kj}\)、\(\Delta D_j=\max_k D_{kj}-\min_k D_{kj}\)。許容値判定も方向ごとに行う。
5. 「帰零差」は最後の零方向再視準と最初の零方向との差として別欄・別ラベルにする。倍角差・観測差の式へ入れない。

### 鉛直角（各目標 j）

1. 天頂角表示であることを明記し、正 \(r_j\)、反 \(\ell_j\) を同一目標で読む。
2. 高度定数（全差）：\(K_j=r_j+\ell_j-360^\circ\)。
3. 補正済み天頂角：\(Z_j=\{r_j+(360^\circ-\ell_j)\}/2=r_j-K_j/2\)。高低角は \(\alpha_j=90^\circ-Z_j\)。
4. 2方向以上で \(\Delta K=\max_jK_j-\min_jK_j\)。許容値と比較するのは \(\Delta K\) であり、\(\Delta(K/2)\) ではない。
5. スライドでは「高度定数 \(K\)（正反和の全ずれ）」と「片面補正量 \(K/2\)」を別色・別欄にし、`i` を使う場合は最初に符号付き定義式を置く。
