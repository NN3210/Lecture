# 第5回 イラスト生成の指示（Codex、gpt-6-astra）

あなたは測量学の講義資料の図版担当です。組み込みの画像生成ツール（image_gen）で、次の 3 枚の概念イラストを作り、`materials/slides/第05回_トラバース測量I/illustrations/` に PNG で保存してください。作業ディレクトリは `Surveying/` です。

## 共通の指定

- 横長 16:9、長辺 1600 px 程度の PNG（RGB）。
- **文字・数字・ロゴ・記号列は一切入れない**（生成画像の文字は崩れるため）。プロンプトにも「no text, no numbers, no letters, no logos, no watermark」を明記する。
- 写実的な人物・風景は求めない。教科書の図版（plate）のような、落ち着いた温かみのあるアイボリー背景（#FAF9F5 付近）、線は紺（#1F4E79）、強調は青緑（#13877B）と橙（#BD512B）の少色構成。平面的で整った概念図。
- 実在の製品・企業ロゴ・地名・人物を描かない。
- 生成後、Pillow で PNG の形式・大きさを確認し、画像を目視して、文字や数字の混入、崩れた形があれば作り直す。
- 第3回の記録 `materials/slides/第03回_測量の座標/illustrations/生成プロンプト.md` を読み、同じ書式で `materials/slides/第05回_トラバース測量I/illustrations/生成プロンプト.md` を日本語で作る。各画像について、使用ツール、出力ファイル、指定（大きさ・文字なし）、生成・確認結果（日付 2026-10-22、形式、画素数、やり直した回数）、実際に使ったプロンプト（```text ブロック）を記録する。

## 3 枚の内容

1. `title_hero.png`（表紙）
   俯瞰で見た農地（水田や畑の区画）を囲む多角形の測線。頂点に小さな杭または三脚の記号を置き、辺は矢印付きの線で順に結んで一筆書きのように見せる。区画の緑・黄土色は控えめに、測線の紺を主役にする。
2. `traverse_chain.png`（5-1 トラバース測量とは）
   測点を折れ線でつなぎ、各頂点で角（扇形の弧）、各辺で距離（両矢印）を測っていく様子。三脚に載せた測量器械と反射プリズムの簡略シルエットを 2〜3 個。角の弧は青緑、距離の矢印は橙。
3. `ts_coordinate.png`（5-6 TS の座標観測）
   トータルステーションの簡略シルエットから、方向と距離を表す矢印が座標格子上の点へと変わるイメージ。格子・矢印・点で表し、器械の画面には抽象的なバーだけを描く（数字は描かない）。
