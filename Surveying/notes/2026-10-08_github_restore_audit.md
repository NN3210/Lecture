# Surveying：GitHub mainからの復元可否監査

監査日：2026-10-08（日本時間）。対象：Surveying以下の全ファイル（隠しファイルを含む）。ファイルの削除・教材の変更は実施していない。

## 結論

**現状では、ローカルを削除しても全資料を復元できるとはいえない。**

監査開始時の49ファイルのうち、48ファイルはGitHub mainに保存されている。残る `materials/2_測量学_誤差.pptx` は未追跡で、mainのツリーにも過去履歴にも同一内容が存在しない。このファイルを失うと、確認したGitHub mainからは復元できない。GitHub外のバックアップの有無は未確認。

## 照合結果

比較元はGitHubの `refs/heads/main` を `git ls-remote` で確認し、`git fetch origin main` で取得した次のコミット。

`a45242e5cf9984a2b6791cce2167a591ddb049c8`

監査開始時のローカルHEAD・main・origin/mainはすべてこのコミットで一致していた。

| 確認項目 | 結果 |
| --- | --- |
| 監査開始時のローカルファイル | 49件、合計8,404,586バイト |
| GitHub mainのSurveyingファイル | 48件 |
| バイト単位で完全一致 | 32件 |
| Gitの正規化後に一致 | 16件（テキストの改行コード差） |
| 追跡済みファイルの内容変更・削除 | 0件（ステージ済み・未ステージとも） |
| 未追跡の既存資料 | 1件（下記PPTX） |
| gitignore対象ファイル | 0件 |
| mainの未プッシュコミット／GitHub側のみのコミット | 0件／0件 |
| ローカル他ブランチのmainに含まれないコミット | 0件 |
| 50MB超のファイル | 0件 |
| LFSポインタ・シンボリックリンク等 | 0件 |

`core.autocrlf=true` が設定されている。16件はGitHubのLFに対しローカルにCRLFが含まれる差（混在を含む）であり、Gitへの登録内容は一致する。通常のcloneで資料の内容は復元できるが、OS・改行設定によってテキストのバイト列は変わり得る。

同じ授業の登録済みPPTXがあっても、このPPTXと同じファイルであるとは扱えない。全資料の復元を可能にするには、公開可能な内容であることを確認してこのPPTXをmainへ登録・pushするか、別の確実なバックアップを用意し、その復元を確認する必要がある。今回の依頼は照合・監査なので、この既存PPTXの公開登録は行っていない。

## 方法と証拠

- 全ファイルを列挙し、GitHub mainの全48blobを読み出してGitオブジェクトのハッシュを検証した。各ローカルファイルとバイト列・SHA-256・Git正規化後blobを比較した。
- `git status --untracked-files=all --ignored`、`git check-ignore`、インデックス、履歴差分も確認した。gitignoreの規則自体には動画・点群・一時ファイル等があるが、該当する現存ファイルはなかった。
- ファイル別の証拠は [監査一覧CSV](2026-10-08_github_restore_inventory.csv)。CSVは報告・ログ追記前の固定スナップショットで、既存49件に今回追加した監査スクリプト1件を加えた50行。CSV自身は自己参照となるため除外している。
- 監査スクリプトは `scripts/audit_github_restore.py`。本監査で作成する報告・CSV・スクリプト・作業ログ追記は別途mainにcommit/pushする。初回スナップショットの未追跡スクリプト表示は、その保存前の状態を示す。
- Surveying外には `.claude/worktrees/` の未追跡表示がある。別作業ツリーは以前のmainに含まれるコミットを指していた。このフォルダ内の未登録ファイルまでを本監査で保証するものではない。

## 再確認・復元手順

Surveyingで次を実行すると、保存後の最新状態を読み取り監査できる。出力先を指定しない実行はファイルを作成・更新しない。

```powershell
git fetch origin main
python scripts/audit_github_restore.py
```

GitHubのリポジトリから別の新しい場所へ `main` をcloneすれば、mainに保存済みのSurveying資料は取り出せる。今回、削除を伴う復元実験はしていない。新規cloneによる独立した復元実験も未実施で、判定はGitHubが広告するmainと取得済み全blobの照合による。

Gitはファイル内容を保存するが、空ディレクトリ、更新日時、Windowsのアクセス権、ソフトの導入状態までは再現しない。教材ファイルの復元と、スライド再生成の実行環境の復元は別であり、後者の検証は今回の範囲外。

監査結果を隠さないため、未追跡PPTXと範囲外の作業ツリーはそのまま残す。したがってリポジトリ全体の `git status` はcleanにはならない。既存資料を削除・変更・公開せず、今回の監査成果物のみを保存する。
