### 2.3 統括側の推測（資料には書かれていない。集計から読み取ったもの）

1. **WHY が最初で 100% 先行するのは、後の段階の「問い」を先に置くため**。問い型の導入 34 件のうち、動画は末尾で問いを回収する（038・047・084・091）。問いが無いと、楕円体や縮尺係数は「暗記すべき数字」にしか見えない。
2. **SHAPE → HEIGHT が 100%、GEOID → HEIGHT が 63%** なのは、「楕円体高」が楕円体を知らないと定義できないからである。h＝H＋N の式は、楕円体（h の基準）とジオイド（H の基準）の両方を見せた後にしか出せない。
3. **GEOID → DATUM 63%、HEIGHT → DATUM 7 回** は、「高さの基準（ジオイド）を決めた。次に水平位置の基準（楕円体の置き方＝測地系）」という流れが多数派であることを示す。逆順（測地系 → ジオイド）は少数。
4. **PROJ → TMUTM 100%、PROJ → MAPPROJ 87%、MAPPROJ → TMUTM 75%** は、「投影とは何か → 図法の例（メルカトル）→ 測量で使う横メルカトル・UTM」の順で、UTM を見せる前にメルカトルを知っている必要があることを示す。
5. **PROJ → SCALE 100%、TMUTM → SCALE 79%** は、縮尺係数が「投影の歪みの数値化」として投影の直後に出る一方、UTM の 0.9996 や 19 系の 0.9999 という数値はその後に出ることを示す。つまり「縮尺係数とは何か」は UTM の数値より前、計算（係数補正）は後。
6. **AXIS と CALC が交互に出る（50%）** のは、軸の約束（北・方向角・象限）と座標計算（順・逆）を 1 枚ごとに往復するためである。軸の約束をまとめて先に出し、計算まで離すと、計算で「なぜ X が北か」に戻ってしまう。
7. **EX が最後（0.89、51% の資料にある）** は、演習が各段階の確認ではなく、章末のまとめとして置かれることを示す。ただし CALC を含む資料は数値例（1 つの問題を最後まで）を途中に置く（051・078・082）。

## 5. まとめ（改 2 の骨格）

世界の資料の多数派（A 通し型 27 件＋D 計算型 14 件）に合わせ、改 2 は次の 6 章＋演習で組む。章名は改 1 の視覚版ヘッダー（01 場所を伝える／02 高さをそろえる／03 地球を地図にする／04 現地と図面をつなぐ／05 角と距離で点を探す／06 現場へ）をそのまま使う。

1. START：前回の確認 → **今日のゴール（WHY）** → ここで学ぶこと → 90 分マップ
2. 01 場所を伝える：COORD（校庭 → 定義 → 送り状 → 4 種の住所）→ SHAPE（楕円体）→ **LATLON（新規）**
3. 02 高さをそろえる：GEOID（水面と重力 → ジオイド → T.P. → ジオイド高）→ HEIGHT（三つの面 → h＝H＋N → **数値例 37**）→ 水の流れ → **橋（新規）**
4. 03 地球を地図にする：DATUM（450 m 差 → WGS84/ITRF/JGD）→ ECEF（地心直交 → 基線ベクトル）→ PROJ（みかんの皮 → 投影の 3 方法）→ MAPPROJ（大航海時代 → 作り方 → 面積・距離 → 日本の東の国 → 方位 → 赤道付近が理想）→ **正角と縮尺係数の意味（新規）** → TMUTM（横メルカトル → UTM 0.9996）→ PLANE（19 系 → **定義（新規）** → UTM と 19 系の比較）
5. 04 現地と図面をつなぐ：AXIS（X 北・Y 東 → 象限の符号 → 帯広は XIII 系で座標が負）→ SCALE（102〜109）
6. 05 角と距離で点を探す：AXIS（3 つの北 → 真北方向角 → 方位→方向角）→ CALC（113〜121）→ 第 5 回へ
7. 06 現場へ・TRY・GOAL：GNSS（123・124）→ EX（125〜132）
