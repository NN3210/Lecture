1. ブラウザーのツール（browser_use または computer_use）を使って次の URL を開いてください。
   https://www.gsi.go.jp/sokuchikijun/datum-main.html
2. ページを 1 回スクロールして、見出し（h1〜h3）を上から順に読み取ってください。
3. 次のファイルに Markdown で保存してください（UTF-8）。
   notes/session03_kai2_20261021/codex/test_browser_result.md
   内容：
   - 使ったツールの名前（browser / computer use / shell のどれを、どの順で）
   - 取れた見出しの一覧（順番どおり）
   - ブラウザー操作で困ったこと（なければ「なし」）
4. 最後の返答には、保存したファイル名と見出しの件数だけを 2 行で書いてください。

シェルで curl を使って HTML を取る方法は、ブラウザーツールが使えない場合の代替としてのみ使い、その場合はその旨を書いてください。
