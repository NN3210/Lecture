# 手順書 04：改2 の組み立てと確認

作成日：2026-10-22。担当：Claude（Fable 5.1）。計算機操作（Codex）は使わず、python-pptx と PowerPoint COM で行う。
前の段階は [手順書_03_結果統合と順序の抽象化.md](手順書_03_結果統合と順序の抽象化.md)。

## 1. 目的

[03_順序の抽象化と理由.md](../03_順序の抽象化と理由.md) の飛び石チェック表に従って、改1（132 枚）を並べ替え、使わない枚を外し、橋渡しの枚を足して、改2（108 枚）の pptx・pdf を作る。PowerPoint を手で触らず、構成案（Markdown）だけを直せば何度でも作り直せる形にする。

## 3. 手順

作業ディレクトリは `Surveying/`。Python は `-I` で起動する（外部から来たファイルを読むときの決まり）。

### 3.1 構成案と新規枚を書く

1. `改1_構成診断.md`（改1 の全 132 枚の題・ヘッダー・非表示・重複の一覧と問題点）と `03_順序の抽象化と理由.md` §4（飛び石チェック表）を見ながら、`04_改2構成案.md` の表を書く。1 行 1 枚。順番は 03 の §5 の骨格（なぜ → 地球の形 → 緯度経度 → 高さ → 測地系 → 投影 → 平面直角座標系 → 軸と縮尺係数 → 座標計算 → 演習・まとめ）。
2. 外した枚は同じファイルの §3 に理由付きで列挙する（重複、旧版、範囲外、など）。
3. 章を移した枚（例：改1 の 22「みかんの皮」を 01 章から 03 章へ）は、備考に `header=測量学 第3回  /  03  \|  地球を地図にする` と書く。Markdown の表の中なので縦棒は `\|` と書く。
4. 新規枚は `04_新規枚.md` に書く。カードの本文は「1 行目 / 2 行目」の形で、1 カードあたり全角 40 字前後まで（それより長いと枠からはみ出す。§3.5 参照）。帯（takeaway）は全角 45 字まで。

### 3.2 組み立て

~~~powershell
python -I scripts/kai2_build_pptx.py `
  "materials/slides/第03回_測量の座標/3_測量学_座標系_改1.pptx" `
  "notes/session03_kai2_20261021/04_改2構成案.md" `
  "<一時フォルダー>/kai2_build.pptx" `
  --new-spec "notes/session03_kai2_20261021/04_新規枚.md" --renumber
~~~

出力例：`ページ番号書換 NNN 段落` に続いて `改1 132 枚 → 使用 104 枚、削除 28 枚、新規 4 枚、ヘッダー書換 3 枚、出力 108 枚`。

スクリプトがやること（この順）：
1. 構成案を読み、改1 に無い番号・同じ番号の重複・仕様の無い新規枚があれば止まる。
2. 新規枚を型紙（改1 の 25 枚目）の複製として末尾に作り、ヘッダー・題・副題・カード 3 枚・帯・発表者ノートを差し替える（最初の run の書式を残す）。
3. `sldIdLst` を構成案の順に並べ替える。
4. 使わない枚の関係（rel）を落として削除する。
5. `show="0"`（非表示）をすべて外す。
6. 備考の `header=` に従ってヘッダーを書き換える（「測量学 第3回  /」で始まる段落を置換）。
7. `--renumber` でページ番号を書き換える。視覚版の「NN / 81」形式の段落は「位置 / 108」に、旧版の数字だけの脚注（スライド下端 15% にある枠の「14」など）は「位置」に。番号の無い枚（旧版の一部）はそのまま。

### 3.3 画像の縮小（50 MB 制限）

組み立て直後の pptx は改1 の画像をそのまま持つので約 56 MB になる。リポジトリの決まり（1 ファイル 50 MB まで）に収めるため縮小する。

~~~powershell
python -I scripts/pptx_compress_images.py `
  "<一時フォルダー>/kai2_build.pptx" `
  "materials/slides/第03回_測量の座標/3_測量学_座標系_改2.pptx"
~~~

既定（長辺 1600 px、300 KB 以上の画像だけ、JPEG 品質 85）で約 29 MB になる。`--quantize`（PNG を 256 色に減色）を付けると約 11 MB まで落ちるが、写真とグラデーションが荒れるので使わなかった。

### 3.4 PDF と PNG の書き出し

PowerPoint COM を使う。Codex の計算機操作と同時に動かすと画面を取り合うので、必ず単独で実行する。

~~~powershell
.\scripts\pptx_export.ps1 -Pptx "materials/slides/第03回_測量の座標/3_測量学_座標系_改2.pptx" -PngDir "<一時フォルダー>/kai2_png"
~~~

PDF は pptx と同じフォルダーに同名で出る。PNG は `スライド1.PNG` … `スライド108.PNG`（1280×720）。

### 3.5 目視確認

1 回目の書き出しで次の枚を Read で見た：新規 4 枚（14・23・69・73）、ヘッダーを書き換えた 2 枚（29・58）、非表示から戻した「今日のゴール」（6）、章の切れ目（21・75）、最終枚（108）。

| 見た点 | 結果 |
| --- | --- |
| ページ番号「NN / 108」 | 全枚で位置と一致。 |
| ヘッダー（章番号と章名） | 29（みかんの皮）と 58（日本の東の国）が「03 \| 地球を地図にする」に変わっている。 |
| 新規枚のカードの文字 | 69（正角）のカード 1 が枠の下にはみ出していた。14（緯度経度）の帯が 2 行になり下端にかかっていた。 |
| 新規枚の見た目 | 型紙と同じ配色・配置。カード見出し・番号札・帯の書式は保たれている。 |
| 章の連続（python-pptx で全枚のヘッダー文字列とページ番号を抜き出して確認） | 非表示 0、ページ番号は全枚一致。13 枚目（楕円体 GRS80、改1 の 28）だけが「02 \| 高さをそろえる」のまま 01 章の中にあった → 構成案の備考に `header=…01…` を足して組み直した。旧版由来の 47 枚（30〜52 など）はヘッダー自体が無い（改1 のまま。見た目が 2 種類混ざるのは改1 と同じ）。 |

直し方：`04_新規枚.md` の該当行を短くして §3.2〜3.4 をもう一度実行する（pptx を直接触らない）。今回は 69 のカード 1 を「図上の角＝現地の角なら、方向角をそのまま計算に使える / 角がひずむ図法では、補正が方向ごとに変わる」、14 の帯を「緯度・経度は角度。経度 1° は赤道で約 111 km、帯広では約 82 km と、場所で長さが変わる。」に縮めた。

章の連続は、次の 1 行スクリプトで全枚のヘッダーとページ番号を抜き出して確かめる（PNG を 108 枚見るより速い）。

~~~powershell
python -I -c "import sys,re; from pptx import Presentation; p=Presentation(sys.argv[1]); [print(i, [''.join(r.text for r in q.runs) for s in sl.shapes if s.has_text_frame for q in s.text_frame.paragraphs if ''.join(r.text for r in q.runs).startswith('測量学 第3回') or re.match(r'^\d+ / \d+$', ''.join(r.text for r in q.runs))]) for i,sl in enumerate(p.slides,1)]" "materials/slides/第03回_測量の座標/3_測量学_座標系_改2.pptx"
~~~

2 回目の書き出し後、同じ枚を見直し、さらに 108 枚すべての PNG を Sonnet のサブエージェントに「文字のはみ出し・重なり・空枠・番号の不一致」の観点で見させた（繰り返し作業は Sonnet に回す決まり。108 枚で約 3.5 分、約 9 万トークン）。指摘は次のとおり。

| Sonnet の指摘 | 判断と対応 |
| --- | --- |
| 旧版由来の 10 枚（2・4・10・15・16・19・30・70・71・72）の脚注が「1」「14」「37」など改1 の古い番号のまま | 番号書換が「NN / 81」形しか拾っていなかった。`--renumber` を拡張し、下端 15% にある「数字だけ」の枠も位置番号に書き換えるようにして 3 回目の組み直し（§5）。 |
| 旧版由来の 48 枚にヘッダー「測量学 第3回 /」が無い。うち 38 枚（7・27・31〜52・54〜57・59〜68）は脚注の番号自体が無い | 改1 のまま（旧版と視覚版の 2 種類の見た目が混ざるのは改1 と同じ）。今回は直さない。 |
| 3・5 枚目（前回の解答の表）の最下行が帯に少し重なる。107 枚目の「正確な数字へ。」が帯に接する | 改1 の視覚版の枚そのもの（組み立てで中身は触っていない）。授業で読める範囲なので今回は直さない。直すなら改1 側の表の高さを縮める。 |
| 44・56 枚目で小さい画像が大きい図に重なる。66〜68 枚目の図の下の白い帯が空 | 旧版の図の重ね表示（アニメーション前提の作り）。改1 のまま。 |
| 13 枚目（02）の直後に 14 枚目（01）で章番号が戻る | §3.5 の表のとおり、13 枚目のヘッダーを 01 に直した。 |

既知の点（改1 由来で今回は直していない）：58 枚目「日本の東に位置する国は？」の下の帯の文は改1 の 81 枚目のままで、29 枚目「みかんの皮」と同じ文（「角・面積・距離を…保つことはできない。」）になっている。方位の導入としては「地球は丸い。東は赤道に沿った向きではない」のような文が合う。直すときは PowerPoint で改1 の 81 枚目を直してから組み直す。

## 5. 結果

- 改1 132 枚 → 改2 108 枚（使用 104、削除 28、新規 4、非表示 19 枚のうち 2 枚を表示に戻して採用・17 枚を削除、ヘッダー書換 3：改1 の 22 と 81 を 03 章へ、28 を 01 章へ）。
- pptx 約 56 MB → 約 29 MB（画像縮小）。pdf 約 8 MB、108 ページ。
- 組み直しは 3 回：1 回目で新規枚 2 枚の文字あふれ、2 回目で 13 枚目の章ヘッダー、3 回目で旧版由来 10 枚の古い脚注番号を直した。3 回目の後に python-pptx で全枚のヘッダーと番号を抜き出し、13 枚目が 01、旧版の脚注が位置番号になっていることを確認した。
- 残っている改1 由来の見た目の差（旧版 48 枚にヘッダー無し、3・5・107 の帯との接触、44・56・66〜68 の図の重ね表示）は §3.5 の表に記した。
