## 4. 国家資格としての位置付け・登録制度（一次資料）
| 項目 | 内容 | 出典 |
|---|---|---|
| 位置付け | 測量法に基づく国家資格。試験合格は「資格を有する」要件を満たすだけで、国土地理院が備える測量士名簿・測量士補名簿に登録されて初めて測量士（補）となる。合格しただけでは業務はできない | 測量法第49条、Q&A 1-26 |
| 役割の違い | 測量士は測量に関する計画を作製し又は実施する。測量士補は測量士の作製した計画に従い測量に従事する | 測量法第48条（Web検索結果の引用で確認。条文本体は今回未取得） |
| 登録申請 | 資格を証する書類を添えて国土地理院の長に申請。送付先は国土地理院総務部総務課試験登録係。電子申請（e-Gov）も可 | 測量法第49条、GSI登録案内 |
| 登録の期限・有効期間 | 申請に期限なし。登録後の更新手続きなし | Q&A 2-2、2-3 |
| 測量士補なしで測量士登録 | 資格要件を満たせば可能 | Q&A 2-4 |
| 登録の消除 | 死亡、測量法違反による罰金以上の刑、資格がないことが判明した場合のみ。本人の希望による消除はない | 測量法第52条、Q&A 2-8 |
| 届出義務 | 氏名、事務所・業務所の名称・所在地の変更は名簿記載事項変更届。死亡は相続人が死亡届。罰金以上の刑は本人が届出 | GSI登録案内（施行規則第8条の4、第9条） |
| 証明書 | 登録証明書（願）、合格証明書（合格証書は再発行不可）、名簿記載事項証明書。発行手数料なし、約10日（予備校記事による） | Q&A 1-27、3-1、GSI登録案内 |
| 登録の手数料（登録免許税） | 測量士30,000円、測量士補15,000円、標準処理約50日 | 予備校記事による（GSI一次資料は今回PDF未精読。要確認） |
| 法改正 | 令和6年改正（令和7年4月1日施行）で、登録手続・試験に関する規定は政令から国土交通省令（測量法施行規則）へ。令和7年国交省告示第204号で「同等以上の知識及び技能を有する者」を規定 | 国交省報道発表（令和7年1月14日）、GSI登録案内 |

## 5. 測量法第50条・第51条による資格取得ルート（e-Gov法令の条文）
| 資格 | 号 | 要件 |
|---|---|---|
| 測量士（第50条） | 1号 | 文部科学大臣認定の大学（短大を除く）で測量に関する科目を修めて卒業し、測量に関し1年以上の実務経験 |
| | 2号 | 認定を受けた短期大学（専門職大学の前期課程含む）・高等専門学校で測量に関する科目を修めて卒業（修了）し、3年以上の実務経験 |
| | 3号 | 国土交通大臣登録の測量に関する専門の養成施設で1年以上、測量士補となるのに必要な専門の知識・技能を修得し、2年以上の実務経験 |
| | 4号 | 測量士補で、登録養成施設で高度の専門の知識・技能を修得した者（実務経験の要件なし） |
| | 5号 | 国土地理院長が行う測量士試験に合格した者 |
| | 6号 | 国土交通大臣が上記と同等以上の知識・技能を有すると認定した者 |
| 測量士補（第51条） | 1号 | 認定大学で測量に関する科目を修めて卒業 |
| | 2号 | 認定短大等で測量に関する科目を修めて卒業 |
| | 3号 | 登録養成施設で1年以上、測量士補に必要な知識・技能を修得 |
| | 4号 | 国土地理院長が行う測量士補試験に合格 |
| | 5号 | 国土交通大臣が上記と同等以上と認定した者 |

補足（GSI Q&A）:
- 学科は測量法施行令第14条の学科（土木工学、農業土木、林学、採鉱、天文、地球物理、物理、数学、地理、地質）、それに相当すると国土地理院長が認定した学科、または個別審査を受けた学科が該当（Q2-5）。
- 測量士補試験に合格しても、実務経験だけでは測量士に登録できない。測量士になるには測量士試験合格、または登録養成施設（第50条第4号）で高度の専門知識を修得する必要がある。ただし学歴ルート（大学・短大・高専の対象学科の卒業＋実務経験）なら、測量士補の試験合否や登録の有無に関係なく測量士になれる（Q2-10）。
- 実務経験の確認は「測量に関する実務の経歴証明書」で行い、添付書類は不要（Q2-6、2-7）。実務経験の日数基準は予備校記事によれば、1年=1年以上かつ225日以上、2年=450日以上、3年=675日以上（一次資料で未確認）。
- 養成施設の要件は令和7年に見直され（専任教員数・授業時数・実習機器）、一次資料はGSI「測量に関する専門の養成施設」ページ（今回は未精読）。

## 8. 内容の要約・気づき
- 試験制度の核心: 受験資格は完全に不問。測量士補=択一28問・450点で合格、測量士=午前択一28問（450点以上）＋午後記述（合計910点以上）の二段階基準。
- 科目名は令和7年4月施行の法改正で再編（測地測量・測図測量。三次元点群測量が新たに独立）。令和8年試験からこの体系で出題された。講義で「多角測量・GNSS・水準」を扱う場合は、試験上は「測地測量」にまとまることを伝えるとよい。
- 免除制度は試験側にはない。「午前免除」は土地家屋調査士試験側の制度の話で、予備校記事（W1、W3）が測量士補・測量士の資格保有者に言及しているが、法務省の一次資料は今回確認できず（要確認）。
- 試験合格と登録は別。登録は期限なし・更新なし。登録免許税（30,000円／15,000円）はGSIページで確認できず、予備校記事のみ。
- 測量士ルートの落とし穴（講義向けネタ）: 測量士補試験合格＋実務経験では測量士になれない。測量士になるには測量士試験合格、学歴ルート＋実務経験、または補＋高度養成施設。
- 測量士の合格率は10〜24%台が多いが、令和7年は40.2%と突出して高く（令和6年は13.0%）、令和8年は24.2%。年度変動が大きい。
- 令和9年試験の受験案内は2026年11月末頃に公表見込み（Q&A 1-4）。公表後に本表（日程・手数料・科目）を更新する必要がある。
