## 4. 利用上の注意

- このリポジトリは公開。個人名・連絡先は書いていない（サイト運営者は屋号で表記）。
- kinomise.com から保存した PDF（H20〜H24、H28 士補、H29 士、H27 士午前、H30 士補の by_question）は、同サイトに著作権表示があり再配布条件が明記されていない。国土地理院の試験問題そのものを転載したものだが、公開リポジトリに置き続けるかはリポジトリ管理者の判断に委ねる。除外する場合は該当フォルダを削除し、報告ファイル（整理済みの表）だけを残せばよい。
- 日本測量協会・予備校の PDF（`_reference/jsurvey_*.pdf`）は案内資料で、内容の引用は報告ファイルに要約した範囲にとどめている。
- 報告の「出題のポイント」は公式解説ではない。問題文の確認は必ず原 PDF で行う。

## 5. 再生成の手順

1. 報告ファイル（01〜34）の `## 問題一覧` 表、午後の大問表を修正する。
2. `python -I Surveying/scripts/exam_build_kakomon.py` を実行すると、`materials/exam/測量士補_測量士_過去問集.md` の `GENERATED_TABLES_START`〜`END` の間が差し替わる。
3. 学習戦略文書の分野配分表は手書きなので、報告の `## 分野別の出題数` を直した場合は手で反映する。
