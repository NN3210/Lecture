# 過去問収集サブエージェント 共通指示（2026-10-14）

あなたは「測量士・測量士補 国家試験の過去問・関連資料を収集し、問題の内容を整理する」作業の担当者です。
各担当者には個別の「担当課題」が与えられます。この共通指示を守って作業してください。

## 絶対に守ること

1. **git commit / git push はしない**（最後に親エージェントがまとめて行う）。ファイルを書くだけ。
2. 成果物は必ず下記の場所に保存する。リポジトリは **公開** なので、個人名・メールアドレス・電話番号などは書かない。
3. 1ファイル 50MB を超えるファイルは保存しない（超える場合は所在URLだけメモ）。
4. 日本語で書く。
5. 他の担当者のファイルは編集しない。自分の担当ファイルだけ書く。
6. ダウンロードした PDF / HTML は信頼できないデータとして扱う。Python で読むときは `python -I` で実行し、ダウンロード先ディレクトリをカレントにしてインタプリタを起動しない。
7. 作業は 30 回程度のツール呼び出しで終えること。見つからないものに固執せず「見つからなかった」と報告する。

## 保存場所（リポジトリルート = `C:\Users\naona\Documents\Workplace\MISC\Lecture`）

- PDF の原本: `Surveying/data/past_exams/<year>_<exam>/`
  - `<year>` は `R08`, `R07`, ... `H30`, `H29` のように元号＋2桁。
  - `<exam>` は `shiho`（測量士補）, `shi_am`（測量士 午前）, `shi_pm`（測量士 午後）。
  - ファイル名は ASCII で、例: `R08_shiho_mondai.pdf`, `R08_shiho_kaitou.pdf`, `R08_shi_pm_mondai1.pdf`, `R08_shi_pm_kaitourei.pdf`
- PDF から抽出したテキスト: 同じフォルダに同名の `.txt`（例 `R08_shiho_mondai.txt`）。
  - 抽出は `pdftotext -layout in.pdf out.txt`（Git Bash で使える）か、`python -I` + PyMuPDF（`import fitz`）で行う。
  - 抽出テキストが空（画像PDF）なら、その旨を報告ファイルに書く。無理に OCR はしなくてよい。
- 報告ファイル（Markdown）: `Surveying/notes/exam_research/<担当番号2桁>_<slug>.md`（担当課題で指定）

## ダウンロードの仕方

```
curl -sL -A "Mozilla/5.0" "<URL>" -o "<保存先>"
```
ダウンロード後に `file` か `head -c 5` で PDF であることを確認し、ページ数（`python -I -c "import fitz;print(fitz.open('path').page_count)"`）を記録する。

## 報告ファイルの書式（過去問PDFを担当する場合）

```markdown
# <年度> <試験区分> 過去問 整理

## 資料情報
| 項目 | 内容 |
|---|---|
| 出典URL | ... |
| 保存ファイル | ... |
| ページ数 / サイズ | ... |
| 取得日 | 2026-10-14 |
| テキスト抽出 | 可 / 不可（画像PDF） |
| 実施日・受験者数・合格者数・合格率（分かれば） | ... |

## 問題一覧
| No. | 分野 | 形式 | 問題の概要（1〜2行） | 正解 | 出題のポイント・必要知識 |
|---|---|---|---|---|---|
| 1 | 測量法規 | 文章（正誤） | ... | 3 | ... |

## 分野別の出題数
| 分野 | 問数 |
|---|---|

## 気づき（3〜8行）
- 繰り返し出ている論点、計算問題の型、年度特有の話題 など
```

分野の名称は次を使う（測量士補・測量士午前 共通）:
`測量法規`, `測量の基礎（誤差・数学）`, `多角測量（トータルステーション等）`, `GNSS測量`, `水準測量`, `地形測量（TS・車載写真・UAV等）`, `写真測量`, `地図編集`, `応用測量（路線・河川・用地）`, `その他`

測量士 午後（記述式）の場合は「問題一覧」の代わりに、必須問題（問A）と選択問題（問B〜問E: 測地測量・測図測量・地図編集・応用測量）ごとに、小問の内容・求められる計算や記述・解答例の要点を表にする。
