# 独立レビュー01：座標・方向角・Bowditchの出典

確認日：2026-11-16。制作仕様.md・plan.mdと以下の一次提供元をWeb取得して確認した。既存教材は変更していない。

- **座標軸**：[国土地理院「平面直角座標系」](https://www.gsi.go.jp/LAW/heimencho)の備考1は、原点で子午線に一致するX軸を北正、直交するY軸を東正と定める。改3の「X=座標北、Y=東」と整合する。「全地点でX正方向=真北」と拡張しない。
- **北の違い**：[国土地理院「基準点情報の解説」](https://service.gsi.go.jp/kijunten/contents/data/datums/explain/detail_info.html)の「真北方向角」は、原点から東西に離れた地点でX軸方向と真北がずれると説明する。図のTは「座標北から時計回り」と毎回統一する。この2ページだけで時計回りの定義そのものを引用確認したとは書かず、教材で採用する計算規約として明示する。同ページの「偏角」は磁気偏角なので、講義のトラバース偏角δと混同しない。
- **Bowditchの条件**：[Esri「トラバースの調整」ArcGIS Pro 3.4](https://pro.arcgis.com/ja/pro-app/3.4/help/editing/adjust-traverse-closure.htm)の「コンパス」は、各辺を同程度の精度で測定し、方向と距離の双方に誤差があるとの仮定で、閉合差を辺長比例で配分する方法を説明する。「角度と距離の標準偏差が同じ数値」とは書かない。本文はCompassと表記し、Bowditchの名称は明記していないため、このページの直接引用名は「コンパス調整」とする。Bowditch法の参考説明として用いる。
- **適用範囲**：Esriは製品の調整方法の一次資料であり、日本の公共測量規程ではない。角許容40″は教材仮定と明記する。規程値・標準的な合格精度を出典から推測しない。許容の点検後に補正し、閉合を強制した結果を精度の証明にしない。
- **閉合比**：Esriは1:N表示。本講義のr=e/Pと対応を明示し、N=P/eとする。e=0では比率の逆数を有限値として表示しない。
- 高知工科大学4Traverse.pdfの図式は途中で数学座標へ切り替わるため、そのまま転載・転用しない。

採用推奨：最終出典スライドとREADMEに上記3URL、参照日、各資料が支える項目を記載する。新版の計算規約・授業仮定と外部資料の記述を区別すれば、制作仕様に重大な矛盾はない。
