# 独立レビュー14：逆計算とTS後視

確認日：2026-11-16

対象：`part2.json` の id 28・29・30・33・38、および改3の `inverse.png`・`exercise_inverse.png`・`backsight.png`。原稿・画像は変更していない。

## 判定

**数学上の必須修正なし。** Xを北、Yを東、方向角を北から時計回りとする約束に、逆計算・例題・TS後視が整合している。180°の二重加算を避ける説明も講師ノートにある。

## 確認結果

- **id 28：** P→Qの差を終点−始点で求め、距離を平方和の平方根とする式は正しい。始終点を交換した場合の180°差は異なる2点について成立し、同一点の例外はid 29で明記される。図のA→Bは北西でΔX正・ΔY負、時計回りの大きい方向角となり、本文の規約と一致する。
- **id 29・4象限：** 通常のarctanの主値に対し、(ΔX,ΔY)が(+,+)ならα、(−,+)と(−,−)ならα+180°、(+,−)ならα+360°で正しい。代表値(±1,±1)から45°・135°・225°・315°を独立に照合した。
- **id 29・軸上：** ΔX=0の場合はΔYの正負から90°・270°、ΔY=0の場合はΔXの正負から0°・180°になる。前者は本文とノート、後者はノートで説明され、除算不能の扱いは明確。同一点はS=0・方向未定義とし、atan2(0,0)の実装値を採用しない説明も正しい。
- **id 29・atan2：** Python/C等の通常のatan2(y,x)規約では、測量座標の引数は(ΔY,ΔX)で正しい。radから度への換算が必要な実装についてもノートが説明している。atan2は象限判定込みなので、その結果へ表の180°・360°を再加算しない。
- **id 30・TS：** 確認時点のJSONは器械B・後視A・前視Cであり、T_BC=mod(T_BA+β,360°)。図もBA=220°、時計回りβ=100°、BC=320°で一致する。AB=40°からBAへ反転する段階で180°を一度使い、既にBAが分かれば再加算しない。ノートの「ここでさらに180°を足してはいけない」が二重加算を明示的に防いでいる。後視誤差で器械点周りに回転する説明、別の既知点による点検も妥当。
- **id 33・38：** ΔX=+80 m、ΔY=−150 m、S=170.000 m。α=−61.927513064147°、T_PQ=298.072486935853°=298°04′21″、T_QP=118°04′21″を再計算した。丸め前の角度から成分(80,−150)を再現し、Q=(1580,2150)へ戻ることも確認した。演習図の北西配置と成分表示も一致する。

## 任意の改善候補

1. **atan2と手計算の使い分けを画面にも一言置くと安全。** id 29は表とatan2式を併記するため、「表はarctan用／atan2は象限補正済み」を本文で見せると、講師ノートを読めない学生にも180°の二重加算防止が伝わる。現状もノートでは説明済みであり、必須修正ではない。
2. **ExcelのATAN2だけ引数規約に注意。** Excelの`ATAN2(x_num,y_num)`は一般的なプログラミング言語と引数順が異なるため、この測量座標では`ATAN2(ΔX,ΔY)`となる。id 29の式をそのままExcelへ入力させる場合のみ、使用ソフトを明示するかこの違いを補足するとよい。通常のatan2(y,x)を示す現在の数学式は正しい。
3. **点名を揃えると照合しやすい。** `inverse.png`はA・B、id 28と38はP・Qを使う。矢印・符号の数学は正しいが、特に解答スライド38でP/Qを図中に探す学生は一瞬迷う可能性がある。

## 180°を足す場面の切り分け

| 場面 | 加算の要否 |
| --- | --- |
| arctanの主値から南側2象限の方向角へ直す | +180° |
| atan2から方向角を得る | 象限による+180°は不要。度換算・0〜360°への整えだけ |
| 前の進行方向ABから後視BAを作る | +180°して整える |
| 既に得た後視BAから前視BCを作る | +βのみ。+180°を重ねない |
| T_PQから反方向T_QPを作る | +180°して整える |

以上の区別は対象原稿の式・講師ノートで成立している。
