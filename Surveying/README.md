# Surveying（測量学・測量学実習）

帯広畜産大学で担当する測量学・測量学実習の教材を作成するワークスペースです。
Claude Code（ローカル）と Codex（Cloud、Lecture リポジトリ全体を環境として使用）が同じ `main` ブランチで作業します。

## 進め方

1. 作業前に `git pull` して最新にする。
2. 成果物は必ずこのディレクトリ以下に保存し、区切りごとに commit / push する（リポジトリ直下の `AGENTS.md` のルールに従う）。
3. 何をしたかは `notes/worklog.md` に追記する。次に作業するエージェントや人は、まず `notes/` を読む。

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `notes/` | 背景メモ、作業ログ、決定事項 |
| `materials/` | 講義スライド・配布資料・課題 |
| `data/` | 実習用データ（匿名化済みのもののみ） |
| `scripts/` | 計算・作図スクリプト |

## 背景

2026 年度の測量学実習の経緯（会場・協力企業・日程）は `notes/2026_practicum_summary.md` にまとめています。
