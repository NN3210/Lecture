# 第03回 測量の座標 — 手計算テスト 模範解答と採点基準

- 数値は `scripts/check_exercise_03.py` で検算済み。$R = 6370$ km。
- 座標・距離は m で小数第3位、角は秒まで。途中で丸めない。

## 問1 座標の逆計算と順計算（5点）

### (1) 逆計算（3点）

$$
\Delta X = X_B - X_A = 1050.000 - 1200.000 = -150.000\ \mathrm{m},\qquad
\Delta Y = Y_B - Y_A = 600.000 - 800.000 = -200.000\ \mathrm{m}
$$

$$
S_{AB} = \sqrt{\Delta X^2 + \Delta Y^2} = \sqrt{150^2 + 200^2} = \sqrt{62500} = 250.000\ \mathrm{m}
$$

$$
\arctan\frac{\Delta Y}{\Delta X} = \arctan\frac{-200}{-150} = \arctan(1.3333\ldots) = 53°07′48″
$$

$\Delta X < 0$、$\Delta Y < 0$ なので第 3 象限（南西）。$180°$ を加えて

$$
T_{AB} = 53°07′48″ + 180° = \boxed{233°07′48″}
$$

検算：$250.000 \cos 233°07′48″ = -150.000$、$250.000 \sin 233°07′48″ = -200.000$。

| 採点 | 点 |
| --- | --- |
| $\Delta X$・$\Delta Y$ の符号と値 | 0.5 |
| $S_{AB} = 250.000$ m（式と値） | 1.0 |
| 象限判定（第 3 象限、$+180°$） | 0.5 |
| $T_{AB} = 233°07′48″$（±2″） | 1.0 |

よくある誤り: $\arctan$ の値 $53°07′48″$ をそのまま答える（第 1 象限と混同）。$\Delta Y/\Delta X$ を $\Delta X/\Delta Y$ と逆にする（$36°52′12″$ が出る）。

### (2) 順計算（2点）

$$
\Delta X = 200.000 \cos 30° = 173.205\ \mathrm{m},\qquad
\Delta Y = 200.000 \sin 30° = 100.000\ \mathrm{m}
$$

$$
X_C = 1200.000 + 173.205 = \boxed{1373.205\ \mathrm{m}},\qquad
Y_C = 800.000 + 100.000 = \boxed{900.000\ \mathrm{m}}
$$

検算：逆計算で $S = 200.000$ m、$T = 30°00′00″$ に戻る。

| 採点 | 点 |
| --- | --- |
| $\Delta X$・$\Delta Y$（$\cos$ が X、$\sin$ が Y） | 1.0 |
| $X_C$・$Y_C$ | 1.0 |

## 問2 距離の換算（5点）

### (1) 水平距離（1点）

$$
S = \sqrt{L^2 - \Delta h^2} = \sqrt{500.020^2 - 4.500^2} = \sqrt{250020.0004 - 20.25} = 499.99975\ldots \longrightarrow \boxed{500.000\ \mathrm{m}}
$$

### (2) 基準面上の距離（1.5点）

$$
S_0 = S\,\frac{R}{R + H} = 500.000 \times \frac{6370000}{6370200} = 499.98430\ldots \longrightarrow \boxed{499.984\ \mathrm{m}}
$$

近似式 $S_0 \approx S\left(1 - \dfrac{H}{R}\right) = 500.000 - 500.000 \times \dfrac{200}{6370000} = 500.000 - 0.0157 = 499.984$ m でも同じ。

### (3) 平面直角座標上の距離（1.5点）

$$
s = m\,S_0 = 0.9999 \times 499.984 = 499.93400\ldots \longrightarrow \boxed{499.934\ \mathrm{m}}
$$

### (4) 補正の向き（1点）

- (2) 標高補正は**短くする**（$-0.016$ m）。標高 $H$ の地表は基準面より地球の中心から遠く、同じ中心角に対する弧が長い。基準面に下ろすと短くなる。
- (3) 縮尺係数の補正は、この地点（$m = 0.9999 < 1$、原点付近）では**短くする**（$-0.050$ m）。原点から東西に約 90 km を超えると $m > 1$ になり、長くする向きになる。

| 採点 | 点 |
| --- | --- |
| (1) $S = 500.000$ m | 1.0 |
| (2) 式（$R/(R+H)$ または $1 - H/R$）と値 | 1.5 |
| (3) 式（$m$ を乗じる）と値 | 1.5 |
| (4) 向きと理由（各 0.5） | 1.0 |

### 発展（加点なし）

$$
S = \frac{s}{m}\,\frac{R + H}{R} = \frac{300.000}{0.9999} \times \frac{6370200}{6370000} = 300.0300 \times 1.0000314 = 300.0394 \longrightarrow 300.039\ \mathrm{m}
$$

設計図の距離は平面直角座標上の距離なので、現地ではそれより約 4 cm 長く測って杭を打つ。
