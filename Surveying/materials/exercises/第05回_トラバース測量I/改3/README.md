## 旧版からの修正

5点の観測値・既知方向角・距離・逆算座標は維持した。観測角和540°01′00″より角閉合差は＋60″となるため、演習には±80″を授業用許容として明示した。講義4点の±40″とは異なり、いずれも規程値ではない。各角等精度を仮定する。

旧版の「辺長は教材用に閉じるため、合計が±1 mm以内なら正しい」という説明を削除した。合成教材の小さな閉合差だけでは実測精度を評価できない。内部値で求めた総和は ΔX＝−0.000501822105… m、ΔY＝＋0.000172928216… m。辺ごとの0.001 m表示を足した総和（0.000 m、＋0.001 m）と区別し、内部値で補正と検算を行う。

方向角の展開は `T_next=mod(T_prev+180°+β,360°)` に統一した。X北・Y東、Tは北から時計回り、βは後視から前視を時計回りに測る角で、この反時計回りループでは内角となる。逆算で同一点なら方向角は未定義。Excelの三角関数にはRADIANSを用い、ATAN2の引数順序を明記した。
