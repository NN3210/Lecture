## 再生成

`Surveying/`を作業ディレクトリとして次を実行する（python-pptx、matplotlib、numpy、Pillowが必要）。既存の`md2pptx.py`を利用する。

```sh
python scripts/build_session02_revised.py
```

初回改訂のPDFは生成したPPTXをLibreOfficeで書き出した。2026-10-08 再改訂のPDFは、Windows上のPowerPoint（COM）を使う`scripts/pptx_export.ps1`で書き出した（84枚）。

```sh
powershell -ExecutionPolicy Bypass -File scripts/pptx_export.ps1 -Pptx <PPTXの絶対パス>
```

指定フォントはNoto Sans CJK JP、行内数式はDejaVu Sans。今回の再生成環境にはNoto Sans CJK JPが無かったため、図中の文字はメイリオで代替した（`build_session02_revised.py`のフォント指定の順による）。フォント未導入の端末では代替フォントによって配置が変わる場合があるため、配布時の見た目はPDFで確認できる。
