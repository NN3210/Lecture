# 第02回 測量の基礎と誤差論

農業農村工学系の学部講義、90分。観測値の最確値と精度を計算し、誤差の種類と重みを説明することを目標とする。日本語の Marp 原稿を正本とし、画像は使用していない。

## 内容と構成

| 区分 | スライド番号 | 枚数 | 時間 |
| --- | --- | ---: | --- |
| 導入 | 1〜5 | 5 | 0〜5分 |
| 講義 | 6〜60 | 55 | 5〜60分 |
| 演習 | 61〜65 | 5 | 60〜85分 |
| まとめ | 66〜68 | 3 | 85〜90分 |
| 合計 | 1〜68 | 68 | 90分 |

講義は誤差の3分類、正規分布、精度と確度、有効数字、算術平均と最小二乗法、残差、2種類の標準偏差、重みと重み付き平均を扱う。例題Aは6回の距離観測、例題Bは回数の異なる2組の群平均である。

確認問題は12・24・36・48・60枚目に置いた。最新技術との接続は54〜57枚目の4枚（TS・GNSSの精度表示、ppm、3回計測、RTK固定解）、倫理は58枚目。全68枚の末尾に2〜4文の発表者ノートを付けた。演習の5枚は25分の作業中に必要に応じて映し、1枚1分では進めない。詳しい演習解説は次回冒頭に行う。

## 再生成方法

HTMLはこのフォルダを作業ディレクトリとして実行する。

~~~sh
npx --yes @marp-team/marp-cli@4.1.2 slides.md -o slides.html
~~~

標準入力を閉じて実行する場合：

~~~sh
npx --yes @marp-team/marp-cli@4.1.2 slides.md -o slides.html < /dev/null
~~~

WindowsのPowerShellからは次の形を使う。

~~~powershell
cmd /c "npx --yes @marp-team/marp-cli@4.1.2 slides.md -o slides.html < NUL"
~~~

PPTX は Marp CLI の `--pptx` では生成できない（この作業環境では headless Chrome/Edge がタイムアウトする）。代わりに `Surveying/` 直下で次を実行する（python-pptx と matplotlib が必要。ブロック数式は mathtext の画像、行内数式は Cambria Math の文字と上付き・下付き書式になる）。

~~~sh
python scripts/md2pptx.py "materials/slides/第02回_測量の基礎と誤差論/slides.md" -o "materials/slides/第02回_測量の基礎と誤差論/slides.pptx" --title "測量学 第2回 測量の基礎と誤差論"
~~~

~~~powershell
.\scripts\pptx_export.ps1 -Pptx "materials\slides\第02回_測量の基礎と誤差論\slides.pptx" -Pdf "materials\slides\第02回_測量の基礎と誤差論\slides.pdf" -NoPng
~~~

全4題の出力を例題・模範解答と照合した。標準偏差は途中で丸めず、最終結果のみ0.01 mmまで四捨五入する。

## 作成時の判断と確認範囲

- 前回演習の実際の問題・解答が指定資料にないため、2枚目はDMS変換と丸めの「復習例」と明示した。実際の出題内容が分かれば、この1枚を差し替える。
- 例題Bと演習問2は、元の観測が同精度・独立で回数だけが異なる設定とした。絶対的な分散は未知で、無次元の相対重みを使い、2個の群平均の残差から共通の分散尺度を推定する。式の $n$ は群数2であり、元の総観測回数5ではない。絶対分散が既知の場合の式も講義で区別した。
- 正規分布の68%・95%は1次元の母分布についての説明とした。少数標本で推定した平均の信頼区間や、GNSSの水平精度指標と同一視しない。
- 課題指定の5ファイルとHTMLのみを作成した。今回の依頼を優先し、作業ログの追記、commit、pushは行っていない。
- フロントマターの完全一致、68枚の区分別枚数、各末尾ノートの文数、表6行以内、数式ブロックを1行とした本文7行以内、確認問題の間隔を静的に点検した。短答・問1・問2の問題文は、改行と空白を除いて配布物と一致する。
- 指定のnpxコマンドはnpmキャッシュへの書込み権限不足（EPERM）で失敗した。その後、既存キャッシュのMarp CLIが4.1.2であることを確認し、そのCLIを直接実行してHTML生成に成功した。新たな依存パッケージやキャッシュは作成していない。
- HTMLのスライド数・数式の変換結果を点検した。ブラウザによる目視点検と印刷レイアウトの確認は実施していない。
