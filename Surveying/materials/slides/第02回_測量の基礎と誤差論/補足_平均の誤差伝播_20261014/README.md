# 平均の誤差伝播：第2回補足スライド

2026年10月14日作成、10月15日に現場例2枚を追加。前回の第2回改訂版の2-4節を、導入から説明する独立した22枚の補足資料。目安は説明20〜25分と確認問題。

## 内容

- 1〜5枚目：反復観測、平均のばらつき、観測モデル、1個の入力の影響。
- 6〜10枚目：分散・期待値、独立な誤差の合成、1/√nの導出。
- 11〜14枚目：4回平均の例、標準偏差の推定、5回観測の計算、回数の効果。
- 15〜16枚目：30 mの基準線の測定計画。1観測の標準偏差6 mm、平均の目標2 mmなら9回以上。目標ごとの回数と所要時間を比較する。
- 17〜20枚目：共通の偏り、相関、確認問題と解答。
- 21〜22枚目：一般の伝播式と出典。

独立・同精度・有限の分散を仮定し、期待値が0の偶然誤差を扱う。母標準偏差はτ、観測データから求める標準偏差は前回に合わせてσとする。前回のσₓ̄は、表示の読みやすさのためσ(x̄)と表記する。標準偏差と最大誤差・信頼区間を区別する。

## 再生成

`scripts/build_mean_error_supplement.mjs`を使用する。利用環境のバンドルを参照する環境変数を設定して実行する（個人の絶対パスは記録しない）。

```powershell
$env:ARTIFACT_MODULES = '<バンドルのnode_modules>'
$env:PRESENTATION_SKILL = '<Presentationsスキルのディレクトリ>'
$env:RUNTIME_PYTHON = '<バンドルのpython実行ファイル>'
$env:PYTHONIOENCODING = 'utf-8'
& '<バンドルのnode実行ファイル>' scripts/build_mean_error_supplement.mjs
```

最終PPTXがすでに存在すると検証ツールは上書きしない。更新時は旧成果物を明示的に版管理し、出力名を変更する。`build/`は検証中の中間ファイル用で、内容を確認した後に不要な複製や環境依存の検証記録を削除できる。
