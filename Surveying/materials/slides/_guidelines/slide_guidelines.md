# 講義スライド作成指針（測量学・全回共通）

- 作成: 2026-10-08、Claude Code（Fable 5.1）。Codex（gpt-6-astra）がスライドと演習を作成し、Claude が本指針に照らして点検する。
- 対象: `materials/lecture_plan_13.md` の第 2〜14 回。各回の到達目標・講義内容・演習・試験で問われる型は講義計画が正。本指針は「どう作るか」を定める。

## 1. ファイル形式と置き場所

| 成果物 | パス | 形式 |
| --- | --- | --- |
| スライド原稿（正本） | `materials/slides/第NN回_テーマ/slides.md` | Marp 形式の Markdown（下記 2 節） |
| スライド書き出し | 同フォルダ `slides.pptx`, `slides.pdf`, `slides.html` | HTML は Marp CLI で生成（`npx @marp-team/marp-cli@4.1.2 slides.md -o slides.html`）。pptx は `scripts/md2pptx.py`、PDF は `scripts/pptx_export.ps1` で生成（Marp の `--pptx`/`--pdf` はこの環境では headless ブラウザが動かず失敗する）。HTML はクラウド閲覧用 |
| フォルダ説明 | 同フォルダ `README.md` | 内容・枚数・再生成コマンド |
| 演習（手計算テスト） | `materials/exercises/第NN回_テーマ/exercise.md` | 問題文・計算表・提出欄 |
| 演習解答 | `materials/exercises/第NN回_テーマ/exercise_answers.md` | 途中式つきの模範解答、採点基準 |
| 数値検算スクリプト | `scripts/check_exercise_NN.py` | 演習・スライド例題の数値を Python で再計算 |

- pptx・pdf は `slides.md` から機械的に生成した派生物なので、本文テキストは `slides.md` で編集し、再生成する（pptx を直接編集しない）。ブロック数式は pptx では画像になる。
- 公開リポジトリなので、個人名・連絡先・学生情報・協力企業名は書かない。

## 2. Marp の書き方

先頭に次のフロントマターを置く。

```markdown
---
marp: true
theme: default
paginate: true
math: katex
size: 16:9
style: |
  section { font-size: 26px; }
  section h1 { font-size: 40px; }
  section h2 { font-size: 34px; }
  table { font-size: 22px; }
  .small { font-size: 20px; }
---
```

- スライドの区切りは `---`。1 枚目はタイトル（科目名、回、テーマ、到達目標）。
- 発表者ノートは各スライドの末尾に HTML コメント `<!-- ... -->` で 2〜4 文書く（Marp が pptx のノートに書き出す）。「何を話すか」を書き、1 分で話せる分量にする。
- 数式は KaTeX（`$...$`、`$$...$$`）。pptx・pdf・html のすべてで同じ見た目になる。
- 画像は使わない（図が必要なら表・箇条書き・簡単な ASCII 図、または Marp 内の SVG で代替する）。外部 URL の画像を参照しない。
- 1 枚の本文は見出し 1 行 + 本文 7 行以内（表なら 6 行以内）。詰め込むより枚数を増やす。
- 見出しに節番号を付ける（例「2-3 残差と最確値」）。学生が配布 PDF から戻れるようにする。

## 3. 枚数と時間配分

講義計画の標準配分（導入 5 分、講義 55 分、演習 25 分、まとめ 5 分）に対し、**1 枚あたり約 1 分**を目安にする。前後してよい。

| 区分 | 時間 | 枚数の目安 | 内容 |
| --- | --- | --- | --- |
| 導入 | 5 分 | 4〜6 枚 | タイトル、前回演習の解答確認、本日の到達目標、目次 |
| 講義 | 55 分 | 48〜58 枚 | 原理・公式・手順・例題・最新技術との対応 |
| 演習 | 25 分 | 3〜5 枚 | 問題文（配布物と同じ）、計算手順、提出方法。学生が計算している間に映す |
| まとめ | 5 分 | 3〜4 枚 | 要点、試験で問われる型、次回予告 |
| 合計 | 90 分 | 60〜70 枚 | |

- 講義部分は「定義 → 公式 → 例題（数値を入れて途中式を見せる）→ 注意点」の順で 1 概念あたり 3〜6 枚。
- 例題は演習と同じ型で、数値だけ変える。例題の数値は演習の検算スクリプトで同時に検算する。
- 10〜15 枚ごとに「ここまでの確認」（1 問の短い問い）を入れ、話す側の区切りにする。

## 4. 数式の扱い（大学生向け）

- 記号は最初に出すスライドで定義し、以後は同じ記号を使う。回をまたいでも変えない。
- 公式は「式を示す → 各項の意味 → 単位 → 数値例」で扱う。式だけ、言葉だけ、にしない。
- 導出が短いもの（算術平均が残差平方和を最小にすること、最確値の標準偏差が $\sigma/\sqrt{n}$ になること、重みが分散に反比例すること）は、2〜3 枚で導出を見せる。暗記ではなく理由を示す。
- 手計算できる桁数にする。距離は mm 単位、角は秒単位。有効数字と丸めの規則をスライドで明示する。

### 第 2 回で使う記号（固定）

| 記号 | 意味 |
| --- | --- |
| $x_i$ | $i$ 番目の観測値、$n$ は観測回数 |
| $\bar{x}$ | 算術平均（同精度のときの最確値） |
| $v_i = x_i - \bar{x}$ | 残差 |
| $\sigma$ | 1 観測の標準偏差 $\sigma = \sqrt{\dfrac{\sum v_i^2}{n-1}}$ |
| $\sigma_{\bar{x}}$ | 最確値（平均）の標準偏差 $\sigma_{\bar{x}} = \dfrac{\sigma}{\sqrt{n}}$ |
| $w_i$ | 重み。一般則 $w_i \propto 1/\sigma_i^2$。同精度の独立観測の平均なら回数 $n_i$ に比例、水準測量で分散が路線長 $S_i$ に比例する条件では $1/S_i$ に比例 |
| $\bar{x}_w$ | 重み付き平均 $\bar{x}_w = \dfrac{\sum w_i x_i}{\sum w_i}$ |
| $\sigma_0$ | 単位重みの標準偏差 $\sigma_0 = \sqrt{\dfrac{\sum w_i v_i^2}{n-1}}$ |
| $\sigma_{\bar{x}_w}$ | 重み付き平均の標準偏差 $\sigma_{\bar{x}_w} = \dfrac{\sigma_0}{\sqrt{\sum w_i}}$ |

- 「確率誤差 $0.6745\sigma$」は旧来の用語として 1 枚で触れるにとどめ、計算は標準偏差で統一する。
- 誤差の種類は「過失（錯誤）・定誤差（系統誤差）・偶然誤差（不定誤差）」の 3 分類で統一し、それぞれ測量機器での具体例と対処（点検・補正・観測方法で消す／統計的に扱う）を対にして示す。

## 5. 演習（手計算テスト）の要件

- 講義計画どおり 2 問を基本とし、関数電卓で 25 分以内に解ける量にする。
  - 問 1: 試験の型。同一距離（または角）の反復観測（5〜6 回）から最確値、残差、1 観測の標準偏差、最確値の標準偏差。
  - 問 2: 実習・現場の型。精度（または回数）の異なる 2 組の観測から重みを決め、重み付き平均とその標準偏差。
- 冒頭に短答（誤差の分類など 3〜4 問、各 1 行）を置いてもよい。合計 25 分を超えない。
- 計算表（残差・残差の二乗・重み×残差の二乗の列）を問題用紙に印刷し、学生が埋める形にする。
- 問題の数値は、残差が mm 単位の整数になり、電卓で丸め誤差が目立たないものを選ぶ。
- 解答は途中式と丸めを明記し、配点（合計 10 点程度）を付ける。解答は学生に配らない前提で別ファイルにする。
- 数値は必ず `scripts/check_exercise_NN.py` で再計算し、スクリプトの出力と解答が一致することを確認する。

## 6. 最新技術との接続と倫理

- 各回 2〜4 枚で、その回の計算が TS・GNSS・UAV などでどう使われているかを示す。第 2 回なら「TS・GNSS が表示する標準偏差」「測距精度 $\pm(a\ \mathrm{mm} + b\ \mathrm{ppm})$ の読み方」「同一点を複数回測って平均する理由」。
- 精度管理と倫理（許容値超過時は再測、観測値を書き換えない、成果を点検する）を 1 枚入れる。
