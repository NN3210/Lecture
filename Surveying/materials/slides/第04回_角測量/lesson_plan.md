# 測量学 第4回 授業計画：角測量

作成日：2026-10-27。対象：測量を初めて学ぶ学生。説明の前提は高校数学までとする。
授業時間：90分。基礎資料：`../../lecture_plan_13.md` の第4回。

## この回を貫く問い

「校庭の2本の杭の開きは何度か。器械の置き方や向きが少し違っても、信頼できる角度を出すにはどうするか。」

前回の距離・座標に「向き」を加える。距離だけでは点の位置は決まらず、次回のトラバースで角と距離を座標につなげる。

## 到達目標

1. 水平角・高低角・天頂角を図で区別し、度分秒を計算できる。
2. 求心と整準の違い、正反観測で小さくできる器械誤差と消えない鉛直軸誤差を説明できる。
3. 方向法の生の読定値から正反平均・零方向への帰零・水平角を計算し、倍角差・観測差・較差を区別して検算できる。
4. 偏心観測を図と座標で説明し、偏心した器械位置からの角と距離を測点中心に戻せる。
5. 許容値を超えた観測を都合よく書き換えず、原因確認・再測を選べる。

## 説明の方針

- 用語の前に、杭・分度器・回転・見上げる角など身近な動作を示す。
- 1枚1論点。投影用スライドに長文を置かず、詳しい説明は解説HTMLと発表者ノートに入れる。
- 同じ観測点 O と目標 A・B を継続して使う。図中の点名・角の向き・数値を資料間で統一する。
- 「見た目を予想する → 図で関係を確認する → 数字を入れる → 自分で確かめる」の順。
- 演習数値は教材用の架空値。許容値は授業内の仮定として明記し、公共測量の規程値と混同させない。
- 装置ごとの補正機能や鉛直角の符号規約には条件を添える。正反平均で全誤差が消えるとは説明しない。

## 数値と定義の統一

- 方向角：座標北（X正方向）から時計回り。Y正方向は東。水平角は指定した基準視準線から時計回り。
- 度分秒：1° = 60′、1′ = 60″。計算内部は秒またはラジアンとし、表示段階で丸める。
- 正反の平均：反読定を±180°して正の読定と同じ周回に合わせ、境界をまたぐ値も連続値としてから平均する。
- 方向法：正と反の各列で零方向の読定を引いた結果を p、q とする。較差 C=p−q、倍角 D=p+q。同一目標について対回間で最大D−最小Dが倍角差、最大C−最小Cが観測差。生読定の正反差・帰零差・平均角の対回差とは別。検証資料は `../../../notes/session04/review05_definitions.md`。
- 鉛直角：基本は天頂角 Z。正反の鉛直読定を ZL = Z + i、ZR = 360° − Z + i と定義する場合、高度定数 K=ZL+ZR−360°、指標誤差 i=K/2、Z = (ZL − ZR + 360°)/2。高度定数の較差にはKを用いる。機器による表示差を注記する。
- 偏心：基本例は O=(0,0)、E=(0,1)m、A=(100,0)m、B=(0,100)m。測量座標（X北・Y東）。Eからの角と距離をOへ戻す。図の縮尺と偏心の誇張表示を明記する。
- 厳密計算と小角近似を混同しない。偏心距離／目標距離が十分小さいときだけ近似が使える。
