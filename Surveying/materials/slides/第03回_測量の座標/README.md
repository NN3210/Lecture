# 第03回 測量の座標

農業農村工学系の学部講義、90分。「座標とは何か」（数学的定義と測量学的意味）から始め、地球の形とジオイド、測地系と投影（メルカトル・UTM・ガウス・クリューゲル）、平面直角座標系、方向角と座標計算を扱い、測量士補試験の出題の型に沿って理解することを目標とする。日本語の Marp 原稿 `slides.md` を正本とし、概念図 21 点は `diagrams/` の SVG（正本）と PNG（スライド埋め込み用）、概念イラスト 7 点は `illustrations/` の PNG を使う。時間配分と内容の設計は [lesson_plan.md](lesson_plan.md) にある。

2026-10-15 の改訂で、ジオイドの説明を高校生にも分かる段階（水面と重力 → 平均海面と検潮所 → ジオイドの定義 → ジオイド高の数字 → 水の流れる向き）に組み直し、座標の理論（点と数の組の 1 対 1 対応、座標変換の不変量、曲面は平面に広げられないこと、CRS）と、測地系・投影座標系（WGS84/ITRF/JGD2011、投影面 3 種、メルカトル、横メルカトル、UTM）の節を新設した。投影のスライドは文字を減らし、全面の図で見せる。

## 再生成方法

`Surveying/` を作業ディレクトリとして実行する。

図（matplotlib、Noto Sans CJK JP または Meiryo）:

~~~sh
python scripts/draw_session03_figures.py    # 図 1〜10
python scripts/draw_session03_figures2.py   # 図 11〜21（2026-10-15 追加）
~~~

イラスト（`illustrations/`）は Codex の画像生成ツールで作ったもので、スクリプトでは再生成できない。作り直すときは `illustrations/生成プロンプト.md` のプロンプトを使う。

PPTX・PDFは、Windows＋Microsoft PowerPointで次を実行する。

~~~sh
python scripts/build_session03.py
~~~

`build_session03_visual.mjs`がArtifact Toolで本文・表を作り、`patch_session03_math.py`がKaTeXのMathMLをOffice Math（OMML）へ変換する。構造・配置・フォントの検証後、PowerPointでPDFを出力する。日本語はMeiryo、数式はCambria Math。本文・表は編集可能。図の内部は画像のため、編集時はSVG正本または作図スクリプトを使う。

必要環境はNode.js、`@oai/artifact-tool`、`sharp`、`katex`、Pythonの`lxml`・`PyMuPDF`・`Pillow`、Microsoft Officeの`MML2OMML.XSL`、Presentationsスキルの検証ツール。標準のCodexランタイムから自動検出する。異なる配置では`ARTIFACT_MODULES`（Nodeモジュール群）、`MARP_MODULES`（KaTeXを含むモジュール群）、`PRESENTATION_SKILL`、`RUNTIME_PYTHON`を指定する。

中間ファイルはこのフォルダーの`build/`、表示点検画像と検証記録は`notes/session03_redesign/`に作る。再生成後には全ページを目視確認する。数式非対応の旧ビューアでは代替のLaTeX文字列になるため、閲覧・配布にはPDFを使う。

[改訂内容と検証方法](../../../notes/session03_redesign/README.md)、[改訂後の一覧](../../../notes/session03_redesign/preview/)も参照。
