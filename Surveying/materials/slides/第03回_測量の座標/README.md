# 第03回 測量の座標

農業農村工学系の学部講義、90分。「座標とは何か」（数学的定義と測量学的意味）から始め、地球の形とジオイド、測地系と投影（メルカトル・UTM・ガウス・クリューゲル）、平面直角座標系、方向角と座標計算を扱い、測量士補試験の出題の型に沿って理解することを目標とする。日本語の Marp 原稿 `slides.md` を正本とし、概念図 21 点は `diagrams/` の SVG（正本）と PNG（スライド埋め込み用）、概念イラスト 5 点は `illustrations/` の PNG を使う。時間配分と内容の設計は [lesson_plan.md](lesson_plan.md) にある。

2026-10-15 の改訂で、ジオイドの説明を高校生にも分かる段階（水面と重力 → 平均海面と検潮所 → ジオイドの定義 → ジオイド高の数字 → 水の流れる向き）に組み直し、座標の理論（点と数の組の 1 対 1 対応、座標変換の不変量、曲面は平面に広げられないこと、CRS）と、測地系・投影座標系（WGS84/ITRF/JGD2011、投影面 3 種、メルカトル、横メルカトル、UTM）の節を新設した。投影のスライドは文字を減らし、全面の図で見せる。

## 再生成方法

`Surveying/` を作業ディレクトリとして実行する。

図（matplotlib、Noto Sans CJK JP または Meiryo）:

~~~sh
python scripts/draw_session03_figures.py    # 図 1〜10
python scripts/draw_session03_figures2.py   # 図 11〜21（2026-10-15 追加）
~~~

イラスト（`illustrations/`）は Codex の画像生成ツールで作ったもので、スクリプトでは再生成できない。作り直すときは `illustrations/生成プロンプト.md` のプロンプトを使う。

PPTX（python-pptx と Pillow が必要。`scripts/md2pptx.py` を継承し、`![代替文](diagrams/名前.svg)` または `![代替文](illustrations/名前.png)` の行で図の PNG を配置する。本文がなければ全面、h1 の表紙なら背景に敷く）:

~~~sh
python scripts/build_session03.py
~~~

PDF は PowerPoint がインストールされた Windows で pptx から書き出す（Marp CLI の `--pptx`/`--pdf` はこの作業環境では headless ブラウザがタイムアウトするため使わない）:

~~~powershell
.\scripts\pptx_export.ps1 -Pptx "materials\slides\第03回_測量の座標\slides.pptx" -Pdf "materials\slides\第03回_測量の座標\slides.pdf" -NoPng
~~~
