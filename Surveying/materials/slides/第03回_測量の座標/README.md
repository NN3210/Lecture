# 第03回 測量の座標

農業農村工学系の学部講義、90分。地球の形と高さの基準、平面直角座標系、方向角と座標計算を扱い、測量士補試験の出題の型に沿って理解することを目標とする。日本語の Marp 原稿 `slides.md` を正本とし、図10点は `diagrams/` の SVG（正本）と PNG（スライド埋め込み用）を使う。時間配分と内容の設計は [lesson_plan.md](lesson_plan.md) にある。

## 再生成方法

`Surveying/` を作業ディレクトリとして実行する。

図（matplotlib、Noto Sans CJK JP または Meiryo）:

~~~sh
python scripts/draw_session03_figures.py
~~~

PPTX（python-pptx と Pillow が必要。`scripts/md2pptx.py` を継承し、`![代替文](diagrams/名前.svg)` の行で図の PNG を下段に配置する）:

~~~sh
python scripts/build_session03.py
~~~

PDF は PowerPoint がインストールされた Windows で pptx から書き出す（Marp CLI の `--pptx`/`--pdf` はこの作業環境では headless ブラウザがタイムアウトするため使わない）:

~~~powershell
.\scripts\pptx_export.ps1 -Pptx "materials\slides\第03回_測量の座標\slides.pptx" -Pdf "materials\slides\第03回_測量の座標\slides.pdf" -NoPng
~~~
