- 作成: 2026-10-14、Claude Code（Fable 5.1）。作図は Codex（gpt-6-astra、`codex exec`）が `scripts/draw_session03_figures.py` で行う。
- 出力先: このフォルダ。各図を SVG（正本）と PNG（dpi 180）で保存する。
- 流儀: `scripts/build_session02_revised.py` の `save()`・`canvas()`・`box()`・`arrow()` と同じ書き方（matplotlib、`Noto Sans CJK JP` → `Meiryo` 代替、`svg.fonttype='path'`、`axes.unicode_minus=False`、色は NAVY `#1f4e79`・TEAL `#13877b`・ORANGE `#bd512b`・GRAY `#526273` の 4 色）。
- サイズ: 横 12 インチ、縦 2.6〜3.4 インチ（スライド下段 2.9 インチ枠に収める）。文字は 12〜16 pt。図中に TeX 数式は使わず、記号は $H$、$h$、$N$ のようにイタリック 1 文字＋添字で書く（matplotlib の mathtext で `$H$` は可）。
- 内容は本教材用の概念図であり、実測データや第三者の図の転載はしない。地図は海岸線を描かず、系の配置を矩形・楕円の模式図で表す。

## 図の一覧

| 番号 | ファイル名 | 内容 |
| --- | --- | --- |
| 1 | `three_surfaces` | 断面図。上から「地表」（なだらかな起伏の線、NAVY）、「ジオイド（平均海面）」（ゆるい波線、TEAL）、「準拠楕円体 GRS80」（ゆるい円弧、ORANGE）。1 点 P から鉛直線を引き、楕円体→ジオイドを $N$（ジオイド高）、ジオイド→地表を $H$（標高）、楕円体→地表を $h$（楕円体高）と矢印で示す。右側に「h = H + N」を文字で添える。 |
| 2 | `geodetic_coords` | 楕円体（扁平な楕円）に赤道面と本初子午線を描き、点 P の緯度 φ（赤道面と法線のなす角）、経度 λ（本初子午線からの角）、楕円体高 h（法線に沿った高さ）を示す。日本付近（北緯 35〜45°、東経 140°付近）に P を置く。 |
| 3 | `three_norths` | 1 点 O から上向きに 3 本の矢印: 座標北（X 軸、NAVY、真上）、真北（TEAL、座標北から**右（東）へ**少し傾ける。帯広のように原点より西側の点の例）、磁北（ORANGE、座標北から左（西）へ約 9° 傾ける）。O から右上へ視準線 OP（GRAY）。座標北→OP の角を「方向角 T」、真北→OP の角を「方位角 α」、座標北→真北の角を「真北方向角 γ（右回りが正）」と小さな弧で示す。右側に「方位角 = 方向角 − 真北方向角（α = T − γ）」と「γ は座標北から真北へ右回りを正。原点より東で負、西で正」を添える。 |
| 4 | `jpcs_zones` | 日本の平面直角座標系 19 系の配置の模式図。日本列島は海岸線を描かず、北海道・本州・四国・九州・南西諸島を大まかな楕円または角丸四角（薄い GRAY）で置き、各系の原点をローマ数字（I〜XIX）付きの点で示す。北海道の XI（道南西）・XII（道央）・XIII（道東）を TEAL で強調し、XIII の原点に「北緯 44°、東経 144°15′」と添える。位置関係は概略でよい（原点の経度順に並べる）。 |
| 5 | `axes_quadrants` | 左半分: 数学の座標（x 右、y 上、角は x 軸から左回り）。右半分: 測量の平面直角座標（X 上＝北、Y 右＝東、角は X 軸から右回り）。右側には 4 象限に符号 (+,+)、(−,+)、(−,−)、(+,−) を書き、方向角 0°・90°・180°・270° を軸の先に添える。 |
| 6 | `scale_factor` | 横軸 Y（km、−180〜+180）、縦軸 縮尺係数 m（0.9998〜1.0002）。曲線 m = 0.9999(1 + Y²/(2R²))、R = 6370 km を NAVY で描き、Y = 0 で 0.9999、Y = ±90 km で 1.0000、Y = ±130 km で 1.0001 の 3 点に注記。m = 1 の水平線を GRAY 破線で、適用範囲 ±130 km を縦の破線で示す。 |
| 7 | `distance_stages` | 左から右へ 4 つの角丸箱を矢印でつなぐ階段図: 「斜距離 L」→「水平距離 S」→「基準面上の距離 S₀」→「平面直角座標上の距離 s」。各矢印の上に換算の名前（「高度角で換算」「標高補正 ×R/(R+H)」「縮尺係数 ×m」）を書く。箱の下に数値例（1000.049 → 1000.000 → 999.984 → 999.884 m）を添える。 |
| 8 | `elevation_reduction` | 同心円の弧。中心を下に置き、内側の弧（半径 R、ORANGE）を「基準面（楕円体面）」、外側の弧（半径 R + H、NAVY）を「標高 H の地表」。中心から 2 本の半径を引き、外側の弧の長さを「S」、内側の弧の長さを「S₀」として、S₀ = S·R/(R+H) を文字で添える。「高い所で測った距離は基準面では短くなる」と注記。 |
| 9 | `forward_calc` | 平面直角座標（X 上、Y 右）に既知点 A と新点 B を置き、A から B への線分（長さ S、NAVY）、A から上へ座標北、座標北から AB への方向角 T を弧で示す。直角三角形の縦辺を「ΔX = S cos T（緯距）」、横辺を「ΔY = S sin T（経距）」と書く。右側に「X_B = X_A + ΔX、Y_B = Y_A + ΔY」を文字で添える。T は 120° 程度で、B が A の南東（ΔX < 0、ΔY > 0）になるようにする。 |
| 10 | `inverse_quadrant` | 4 象限の図（X 上、Y 右）。各象限に ΔX・ΔY の符号と、arctan(ΔY/ΔX) に加える角（第1象限: そのまま、第2象限（ΔX<0, ΔY>0）: +180°、第3象限（ΔX<0, ΔY<0）: +180°、第4象限（ΔX>0, ΔY<0）: +360°）を書く。右側に表形式で同じ内容を置く。 |
