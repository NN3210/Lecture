## 考証方針

1569年のメルカトル世界図が航海用途を掲げたことと、「本人が航海で苦労したから」という個人的な逸話を区別した。後者は今回確認した資料では裏付けを確認できず、史実として採用していない。ランベルトの考案年と後の航空図への利用も分けている。各人物の心理や単一の発明動機は推測で補わない。

欧州と日本を中心とする代表例であり、世界の地図史全体の網羅ではない。ポルトラノは海図の種類、伊能図とカッシーニの地図は測量成果、メルカトル等は投影法、UTMは投影法に規則を組み合わせた座標系である。

図はすべて授業用に作成した概念図・計算図で、古地図の復元や史料画像ではない。比較図の緑の領域は、地球上で同じ角半径8度の球面小円。メルカトルの面積倍率4倍という数値は緯度60度における局所値で、有限サイズの小円全体の倍率ではない。

## 再生成

プロジェクトのルート `Surveying/` から `python scripts/build_map_history.py` を実行する。必要なライブラリは `python-pptx`、`numpy`、`matplotlib`。フォントは Noto Sans CJK JP。

PDFは生成PPTXをLibreOfficeで変換したもの。PowerPointの実アプリによる表示確認は行っていない。構造検証・PDF検証・全ページの表示点検は `notes/map_history_20261020/` に記録する。
