# 斜距離と水平距離：動かして学ぶ補足教材

第3回「測量の座標」のスライド「測った距離を、そのまま地図に使える？」（提示画像の79/108枚目）を補足する、高校生向けの日本語教材です。

## 開き方

`index.html` をダブルクリックするか、Chrome・Edge・Firefoxなどのブラウザーで開いてください。CSS・JavaScript・SVGはすべてHTML内に含まれ、インストールやインターネット接続は不要です。HTMLファイルだけをコピーして配布できます。

画面下の「印刷 / PDFに保存」から印刷できます。印刷時は折りたたんだ補足や解答も開きます。操作した距離・角度は印刷にも反映されます。

## 内容と操作

- 平面図に必要なのは横方向の距離である理由を、三角形と真上から見た図で比較。
- 斜距離10〜200 m、水平からの角度−60〜60°をスライダーで操作。水平距離と中心間の高低差を同時に表示。
- 水平からの角度αと天頂角Zを切り替え、`S = L cos α = L sin Z` を確認。
- TSの光波測距・角度の読取り・内部計算、器械高と目標高の補足。
- 3次元座標計算にも水平への分解が含まれること、スライドの `L → S → S₀ → s` の説明。
- 解答を開ける確認問題2問。

中心間の高低差と地面の標高差を区別しています。基本図は近距離の平面近似です。基準面・投影の補正式は発展欄の概念的な近似であり、実務の精密計算用ではありません。元スライドの画像は転載せず、説明用の図と数値例を新たに作成しました。

Chromiumで角度2方式・斜距離3値・傾斜角5値の30ケースを検算。初期値100 m・30°で水平距離86.60 m、高低差+50.00 m。画面幅320 / 390 / 768 / 1440 pxで横方向のはみ出しがないこと、キーボード操作、リセット、解答の開閉、印刷時の補足展開と復元、JavaScriptエラーがないことを確認しました。IDの重複・目次リンク・外部ファイル依存も確認済みです。
