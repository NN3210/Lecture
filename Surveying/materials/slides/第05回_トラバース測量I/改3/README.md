## 進行

| 時間 | 内容 |
|---|---|
| 0–5分 | 前回の後視・角観測との接続、目標 |
| 5–60分 | 種類と選点、内角点検と調整、方向角、緯距経距、順計算・逆計算、TS |
| 60–85分 | 5点トラバース15分、逆計算7分、検算3分 |
| 85–90分 | 典型的な誤り、出口問題、次回への橋渡し |

37–38枚は演習解答、39–44枚は結合の方向点検・閉合比・コンパス法則・出典です。閉合比とコンパス法則は既存講義計画で第6回の内容なので、標準90分には追加しません。時間配分は設計値で、実授業での所要時間は未測定です。

## 教え方と数値の約束

- Xは座標北、Yは東。方向角Tは座標北から時計回りと定義します。真北・磁北と区別します。
- βは後視から前視へ時計回りに測った角。本例の反時計回りの巡回では内角と一致します。次の方向角は、前の進行方向を180°反転し、βを足して0°以上360°未満へ整えます。
- 距離は必要な換算を済ませた平面計算用距離で、授業では水平距離との差を無視できると仮定します。内部値を丸めず、表示だけ0.001m・1″にします。
- 角の許容40″（講義4点）と80″（演習5点）は授業用の仮定です。規程の値や標準偏差ではありません。各角を等精度と仮定して等配分します。
- 例題・演習は合成データです。ほぼ閉じるよう距離が設計されており、その閉合差を実測精度の証明に使いません。42枚目の配分例は補正を見やすくする別の条件で、43枚目は元の講義例題へ戻ります。
- Excelは青色の入力欄と数式欄を区別しています。内部計算にRADIANSを使い、初期表示のキャッシュも収録しています。編集後はExcel等の再計算を有効にしてください。

## 図と数式

表紙は画像生成AIによる農地・水路・TSの概念画です。写真や実測図ではありません。計算用の幾何図はSVGと高精細PNG、数式はXeLaTeXとLatin Modern系の数式書体で組版しています。PowerPoint内の数式・図は画像ですが、編集用のTeX・SVG・生成コードを保存しています。PPTXの本文はNoto Sans CJK JPを指定しています。端末にこのフォントがない場合は代替フォントとなるため、見た目を固定したい投影・配布にはPDFを使えます。
