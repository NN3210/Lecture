# 第5回「トラバース測量 I」 図の作図指示書

- 作成: 2026-10-22、Claude Code（Fable 5.1）。作図は Codex（gpt-6-astra、`codex exec`）が `scripts/draw_session05_figures.py` で行う。
- 出力先: このフォルダ。各図を SVG（正本）と PNG（dpi 180）で保存する。
- 流儀: 第3回の `scripts/draw_session03_figures.py` と同じ（matplotlib、フォントは `Noto Sans CJK JP` → `Meiryo` の順で代替、`svg.fonttype='path'`、`axes.unicode_minus=False`、色は NAVY `#1f4e79`・TEAL `#13877b`・ORANGE `#bd512b`・GRAY `#526273` の 4 色、背景は白または透明）。角丸の箱と矢印は `FancyBboxPatch`・`annotate(arrowprops=...)` で描く。
- 大きさは 2 種類。**下段用**は横 12 インチ × 縦 2.8〜3.4 インチ（本文の下に置く）。**全面用**は横 12 インチ × 縦 5.0〜5.3 インチ（見出し以外は図だけのスライドに置く）。文字は 12〜16 pt。図中の数式は matplotlib の mathtext（`$T_{AB}$` など）で、1 文字イタリック＋添字までにとどめる。
- 座標の向きは測量の約束（**X 軸が上＝北、Y 軸が右＝東、方向角は X 軸から右回り**）。数学の向きと混同しない。
- 内容は本教材用の概念図であり、実測データや第三者の図の転載はしない。数値は下表の値を使う（`scripts/check_exercise_05.py` で検算済み）。
