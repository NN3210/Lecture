# ナレーション台本（narration.md）の書き方

オンデマンド動画のナレーションは、スライドの発表者ノートをそのまま読ませると不自然になる。
台本は「耳で聞いて分かる日本語」に書き直してから TTS に渡す。この文書は、台本を書く（書き直す）エージェント・人が守る規則。

## 1. ファイルの形式

```markdown
# 第5回 トラバース測量 I ナレーション台本

## 1
<!-- 表紙 -->
測量学、第五回、トラバース測量の一回目です。今日は、閉合トラバースのそっかく誤差を調整し、方向角とイキョとケイキョの計算ができるようになることが目標です。

## 2
<!-- 前回の解答 -->
まず前回の演習の答え合わせです。…
```

- `## 番号` はスライド番号（1 始まり）。番号の後に見出しを書いてもよい（`## 3 方向角の計算`）。
- `<!-- -->` のコメントは読まれない（スライドの見出しのメモに使う）。
- 1 スライドの文章は目安 150〜350 字（45〜100 秒）。400 字を超えるならスライドを分ける。
- `TODO` を含むスライドは音声なし（2 秒表示）になり、ビルド時に警告が出る。

## 2. 読み上げ向けの書き換え規則

| 元の表記 | 台本の書き方 | 理由 |
| --- | --- | --- |
| 第5回、2つ、180 度 | 第五回、ふたつ、百八十度 | **算用数字は漢数字・仮名で書く**。XTTS（cutlet）は算用数字を読まない（第5回 → だいかい） |
| (n−2)×180° | エヌ引く二、かける百八十度 | 記号は読まれないか誤読される |
| ΔX = s cos θ | デルタ エックスは、エス こさいん シータ | ギリシャ文字・関数名を仮名で。コサイン・サインは平仮名（2.1 節） |
| atan(ΔY/ΔX) | アークタンジェント、デルタ ワイ 割る デルタ エックス | 同上。タンジェントは片仮名のまま読める |
| √(ΔX²+ΔY²) | ルート、デルタ エックスの二乗 足す デルタ ワイの二乗 | 同上 |
| 95°01′10″ | 九十五度一分十秒 | ′″ は読まれない |
| 1/10000 | 一万分の一 | 分数の読み |
| 0.9999 | ゼロ点きゅうきゅうきゅうきゅう | 桁が多い小数は一度聞いて確認 |
| +, − の符号 | せい、負 | 「正」単独は XTTS が「ただし」と読む（正反観測・補正はそのまま） |
| 度・分・秒（単位名を並べる） | ど、ふん、びょう | 「度、分、秒」は「たび、ぶん」と読まれる |
| TS, GNSS, EDM | ティーエス、ジーエヌエスエス、イーディーエム | 略語は片仮名で |
| X, Y 座標 | エックス座標、ワイ座標 | 英字 1 文字は片仮名に |

専門用語で読みが揺れるものは、最初に出る箇所だけ括弧で読みを添えるのではなく、**ひらがな・片仮名で書く**（TTS は括弧も読む）。

| 後視・後視点 | こうし・こうしてん | 「ごし」と読まれる |

| 水平角 | すいへいかく | 「みず…」 |

書き方: 「緯距（いきょ）」ではなく「イキョ、つまりエックス方向の成分」のように、仮名で書いて意味を補う。

### 2.1 XTTS（cutlet）向けの追加規則

XTTS の日本語は cutlet（MeCab + UniDic）のローマ字を読む。そのため edge-tts や ElevenLabs では問題にならない次の癖がある（2026-10-22 に第5回 64 枚と 1 文ずつの合成で確認）。

- 片仮名の外来語は英語つづりに戻される。XTTS がそのまま読めた語: タンジェント、アークタンジェント、モード、スライド、プログラム、ルート、メートル、センチメートル、シグマ、イプシロン、プラスマイナス、コンパス、ティー・エス・ピー・キュー・アイ（英字 1 文字）。読めなかった語とその書き方: コサイン → こさいん、サイン → さいん、ミス → 誤り、イラスト → 絵・概念図、本スライド → このスライド、日本語 → にほんご。
- 片仮名の読みを続けて書くと別の語に切られる: デルタビー → 「デルタ ビー」、エックスエー → 「エックス エー」、ピーキュー間 → 「ピーとキューの間」。
- 「イキョ」「ケイキョ」の直後の句読点で ョ が落ちる。「イキョの計算、」「ケイキョです」のように続ける。
- 「正」単独は「ただし」、「度、分、秒」は「たび、ぶん」、「数本」は「すうぽん」、「和か」は「にこやか」。仮名で書く（せい、ど・ふん・びょう、何本か、和、または）。
- 平仮名が逆効果の語もある: たんじぇんと・あーくたんじぇんとは片仮名より悪い。片仮名のままにする。
- 確かめ方: 台本全体を cutlet でローマ字にし（指南書 3 章のコマンド）、`?` と上の誤読が無いことを見る。疑わしい語は `tts_synth.py --engine xtts` で 1 文だけ合成し、`check_asr.py --wav <wav> --text <文>` で聞き取る。

## 3. 話し方の設計

- 1 文は 40〜60 字まで。読点を多めに打つと TTS の間が自然になる。
- 板書の代わりに「スライドの右の表を見てください」のように、画面のどこを見るかを言う。
- 数値の計算は「まず…、次に…、最後に…」と手順を言葉で区切る。式を読み上げるだけにしない。
- 冒頭で到達目標、末尾でまとめと次回予告を入れる（講義計画 `materials/lecture_plan_13.md` の 90 分配分に合わせる）。
- 演習（25 分）は動画では「一時停止して解く」指示を入れ、解答スライドは別の章にする。
- 「えー」「あの」などは書かない。ただし講師の口癖を再現したい場合は `notes/` の話し方分析（circleback-corpus の style）を参照して、語尾（「〜ですね」「〜になります」）だけ寄せる。

## 4. 確認の手順

1. `python scripts/ondemand/build_video.py ... --dry-run` で台本とスライドの対応（台本なし・TODO）を確認。
2. 台本全体を cutlet でローマ字にして、読めない漢字（`?`）と 2.1 節の誤読が無いことを見る（XTTS を使うとき）。
3. まず `--engine edge` で全体を作り、`check_asr.py --narration ... --work ...` で各スライドの CER を見る（2026-10-22 の第5回は 64 枚で 0〜7.6%、平均 2.4%）。目立って高い枚だけ聞き、台本側で直す（無料・速い）。台本を直すと変えた枚だけ作り直される。
4. 直った台本で本人の声のエンジン（`elevenlabs` または `xtts`）に切り替える。`--only 3,5` で直したスライドだけ作り直せる。
5. 字幕（.srt）を目で確認する。字幕は文字数比の近似なので、長い文は分割する。
