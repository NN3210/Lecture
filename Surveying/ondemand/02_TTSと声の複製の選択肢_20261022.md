# TTS と声の複製の選択肢（2026-10-22 時点の調査と判断）

講義動画のナレーションを「講師本人の声に似せた TTS」で作るために、2026-10-22 に調べた選択肢と、この PC（Windows 11、GPU なし、4 コア、16 GB）での判断をまとめる。
料金・制限・モデル名は変わりやすいので、実行時に各出典で再確認すること。

## 1. 用語

| 用語 | 意味 |
| --- | --- |
| TTS（Text-to-Speech） | 文字を音声にする技術。既製の声（話者）を使う |
| 声の複製（voice cloning） | 本人の録音を参照して、TTS の声を本人に似せること |
| ゼロショット複製 | 数秒〜数分の参照音声を渡すだけで、学習なしに声を似せる方式（XTTS、ElevenLabs IVC など） |
| ファインチューニング型 | 本人の録音（30 分〜数時間）でモデルを追加学習する方式（ElevenLabs PVC、GPT-SoVITS、Style-Bert-VITS2 など）。似方は上だが、材料と時間が要る |
| 話者分離（diarization） | 録音の中で「誰がいつ話したか」を区切る処理。Circleback が済ませている |
| 話者埋め込み（speaker embedding） | 声の特徴を数百次元のベクトルにしたもの。2 本の音声のコサイン類似度で同一人物かを判定する（speechbrain ECAPA など） |
| RTF（realtime factor） | 合成に要した時間 ÷ 音声の長さ。1 より大きいほど遅い |

### 実測（この PC、2026-10-22）

| 項目 | 値 |
| --- | --- |
| edge-tts（Keita）2 枚分 57 秒の音声 | 数秒（ネット経由） |
| XTTS v2 日本語 80 字（2 文）、CPU | 音声 12.1 秒、所要 129 秒（モデル読込を含む）。RTF 約 10.7 |
| XTTS v2 日本語、モデル読込後のみ | 61 字 → 音声 11.8 秒を 84 秒（RTF 7.1）、78 字 → 13.3 秒を 50 秒（RTF 3.8）。読込を除けば RTF 4〜7 |
| faster-whisper small（int8、CPU）での聞き取り検査（check_asr.py） | 12 秒の音声を約 4 秒で文字化（モデル読込 6 秒）。読みに直して比べた CER は XTTS 音声 9.7%、edge-tts 音声 8.6〜15.4%（文字のまま比べると 20% 前後。同音の専門用語の誤認識が多いため） |
| XTTS v2 モデル読込 | 初回ダウンロード約 1.9 GB（`~/.cache/huggingface/hub/models--tts-hub--XTTS-v2`）、読込は数十秒 |
| speechbrain ECAPA 類似度（合成音声で検証） | 同一話者 0.84、別話者 0.09〜0.13。モデル読込 5〜19 秒 |
| 動画（1280x720、10 fps、静止画、H.264 crf 20） | 57 秒で約 1.0 MB → 90 分で約 90 MB（音声 128 kbps 分が大半） |

XTTS の RTF 4〜7（読込を除く）は、90 分の講義（音声 60 分）で 4〜7 時間の合成になる。スライド単位のキャッシュ（build_video.py の manifest.json）で直した分だけ作り直せば実用になるが、本番は ElevenLabs のほうが速い。

## 3. 各サービス・モデルの要件（出典から転記、2026-10-22 確認）

### ElevenLabs

- IVC: 参照音声は 1〜2 分で十分、合計 3 分まで。雑音・BGM・他人の声を含まないこと。1 本の長さより「静かで一定の話し方」が効く。有料プラン（Starter 以上）で利用可。
- PVC: 最低 30 分、推奨 1〜3 時間の本人のみの音声。Creator プラン以上。アップロード後に本人確認（指定文を自分の声で読む）→ 学習（数時間〜1 日）。推奨形式は mp3 192 kbps 以上または wav、音量は RMS −23〜−18 dB、ピーク −3 dB。
- 日本語は multilingual v2 と v3 の両方で対応。v2 は安定、v3 は表現力が高いが読みの揺れがある。
- API: `POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}`（ヘッダー `xi-api-key`）。`scripts/ondemand/tts_backends.py` の `synth_elevenlabs` が実装済み。
- 文字数課金。日本語の台本は 1 回 90 分で 1.2〜1.8 万字程度になる見込み。契約プランの月間文字数を確認する。
- 出典: https://elevenlabs.io/docs/ （Voices → Voice cloning の各ページ）、https://elevenlabs.io/pricing

### Coqui XTTS v2（idiap フォーク coqui-tts）

- `pip install coqui-tts[ja]`（日本語の読みに cutlet / fugashi / unidic-lite が入る）。PyTorch 2.9 以降は `coqui-tts[codec]`（torchcodec）も要求される。
- 参照音声: 6 秒以上、できれば 10〜30 秒のクリーンな WAV（22.05 kHz モノラルに整えて渡す）。複数本を渡せる。
- 日本語は 1 文 71 字が上限（超えると途切れる警告）。`split_sentences=True` で「。」区切りに分けて合成する。
- ライセンス: Coqui Public Model License（CPML、非商用）。学内の授業配信は非商用と考えられるが、公開・販売する教材には使わない。
- 出典: https://github.com/idiap/coqui-ai-TTS 、https://pypi.org/project/coqui-tts/ 、https://coqui.ai/cpml

### Qwen3-TTS

- Apache-2.0。多言語（日本語を含む）、ゼロショット複製と声のデザイン。0.6B と 1.7B。GPU 前提の実装で、この PC では現実的でない。
- 出典: https://github.com/QwenLM/Qwen3-TTS

### Chatterbox Multilingual / GPT-SoVITS / Style-Bert-VITS2

- Chatterbox: MIT。多言語版で日本語を含む。https://github.com/resemble-ai/chatterbox
- GPT-SoVITS: MIT。1 分の参照で few-shot、学習は GPU（Colab）。日本語の情報が多い。https://github.com/RVC-Boss/GPT-SoVITS
- Style-Bert-VITS2: 日本語特化。学習に GPU。https://github.com/litagin02/Style-Bert-VITS2

### 話者の判定・整音

- speechbrain ECAPA-TDNN（`speechbrain/spkrec-ecapa-voxceleb`）: 16 kHz モノラルを入力、192 次元の埋め込み。https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb
- 雑音低減: 軽くなら ffmpeg の `afftdn`、強くするなら DeepFilterNet（https://github.com/Rikorose/DeepFilterNet ）。整音をかけ過ぎると声質が変わるので、まず「雑音の少ない区間を選ぶ」ほうを優先する。
- PLAUD の録音: クラウドからの取得は Ogg/Opus 48 kHz モノラル 約 32 kbps（圧縮が強い）。話者判定には十分だが、PVC の材料としては PC のマイクで新規に録る WAV のほうが良い。
- Circleback: PLAUD の録音を自動で取り込み、話者分離済みの文字起こし（`segments[].speaker / start / end / text`、話者名は "Participant N"）を返す。N は会議ごとに振り直されるので、本人がどの N かは会議ごとに判定する。

## 4. 判断（2026-10-22）

1. **段階 1（今すぐ）**: edge-tts で第5回の動画を 1 本作り、台本と動画の作り方を固める。無料で数分。
2. **段階 2（本人の声の試作）**: PLAUD + Circleback から本人の区間を切り出し、XTTS v2 で声の似方を確かめる。無料だが CPU で遅い（90 分の講義で約 10 時間）。似方の確認と台本の読みの検証に使う。
3. **段階 3（本番）**: ElevenLabs IVC（1〜3 分の参照音声）で本番を作る。似方が足りなければ、PC のマイクで 30〜60 分の本人のみの録音を新たに作って PVC にする。
4. GPU のある環境（研究室の計算機、Colab）が使えるなら、Qwen3-TTS（Apache-2.0）を XTTS の代わりに試す価値がある。
