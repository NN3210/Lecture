## 1. 講演タイトル（決定）

### 決定案

> **カエルの目で田んぼを見る**
> **―本州と北海道の水田から考える、生きものと両立する農地整備―**

- 主題 11字、副題 29字。現在のチラシの「講　演：」の行に主題が1行で収まり、副題は次の行に入る。
- 1行しか使えない場所（開催案内の本文、報告書の目次など）では主題だけを使う。

### この題にした理由

1. **「カエルの目で」**：依頼状が講師を選んだ理由として挙げた「カエルを透したユニークな視点」を、そのまま題にした。技術者がふだん見ている水田・畦・水路を、カエルの立場から見直す講演だと一目で分かる。
2. **「本州と北海道の水田から」**：依頼メールが一番聞きたがっている点（本の舞台の本州と、この5年の北海道の比較）を入れた。会員は北海道の技術者なので、「北海道」という語が題にあることが大事。
3. **「生きものと両立する農地整備」**：機構の設立目的にある「農業農村の振興と両立する豊かな田園生態系」の言い回しと、依頼状の目的（社会基盤整備と環境の調和）を合わせた。CPD の受講者にも、何を持ち帰れる講演かが伝わる。
4. **仮題「おおきな生き物～かえる～」をやめる理由**：カエルは小さい生き物なので題と中身が食い違う。また、農地整備の講演であることが題から読み取れない。

### 4つの問いと題の対応

| 依頼者の問い | 題のどこで受けるか |
|---|---|
| ① 北海道での研究対象 | 「本州と北海道の水田から」 |
| ② 北海道の冬と越冬 | 「本州と北海道の水田から」（比較の柱の1つ） |
| ③ 大区画水田の特性 | 「田んぼを見る」「北海道の水田」 |
| ④ 基盤整備で留意すべき点 | 「生きものと両立する農地整備」 |

### 代わりの案（主催者と相談になったとき用）

| 案 | タイトル | 向いている場合 |
|---|---|---|
| B | カエルが冬を越せる田んぼとは ―北海道の大区画水田と農地整備― | 北海道の話（越冬・大区画）を主軸にしたいとき。1月の札幌開催で季節にも合う |
| C | 田んぼのカエル、本州と北海道 ―ダルマガエル研究から見えた農地整備のヒント― | 本の読者が多い・本の紹介を前に出したいとき |
| D | カエルからみた水田と水路 ―生きものに配慮した農業農村整備の勘どころ― | 技術者向けの実務色を最も強くしたいとき |

補足：開催案内（案）の本文には「カエルを食用にする国がある」という段落がある。講演内容とのつながりが薄いので、題が決まったら「本州と北海道の田んぼを、カエルの目で見比べる」趣旨の文に差し替えてもらうよう、主催者に提案してもよい。

## 2. チラシの写真（決定：どんな写真を選ぶか）

### 2.1 写真が果たす役割

チラシの下半分すべてが写真になる。題の **「カエル」と「田んぼ（農地）」が1枚の中に両方写っている写真** を選ぶ。カエルだけの写真では、生きものの観察会のチラシと区別がつかない。田んぼだけの写真では、カエルの講演だと分からない。

### 2.2 第1候補（これを探してほしい）

**北海道の水田の畦（あぜ）や水際にいるカエルを、低い位置から撮り、背景に広い水田が写っている写真**

| 要素 | 指定 |
|---|---|
| 主役 | カエル1匹。北海道で撮ったもの（ニホンアマガエルかエゾアカガエル）が最もよい。題の「北海道」と合う |
| カエルの大きさ | 画面の横幅の **1/4〜1/3**。小さすぎると印刷で何か分からず、大きすぎると背景の田んぼが消える |
| カエルの位置 | 左右どちらかの **3分割線上**（画面を縦に3等分した線のあたり）。真ん中に置かない |
| 向き | カエルの頭が **画面の空いている側（田んぼが広がる側）を向いている** もの。見る人の目がカエルの視線に沿って田んぼへ流れ、「カエルの目で田んぼを見る」という題そのままの絵になる |
| カメラの高さ | **地面すれすれ（カエルの目の高さ）**。人の目の高さから見下ろした写真より、題の意味が伝わる |
| ピント | カエルの **目** にピントが合っていること。背景はぼけていてよい（ぼけていても「水田だ」と分かる程度に） |
| 背景 | 水を張った水田、苗の列、畦・水路などの農地の構造物。地平線や防風林、十勝らしい広い空が入るとさらによい（北海道の大区画水田だと伝わる） |
| 季節 | 田植え後〜初夏（水面と若い苗の緑）。夏の稲の中にいるアマガエルも可 |
| 画面の比率 | 横長 4:3。3:2 のカメラで撮った写真は、左右を少し切ることになるので、カエルが端に寄りすぎていないものを選ぶ |

**イメージ（文字で描いた構図）**

```
┌──────────────────────────────┐
│  空・防風林・地平線（上 1/4）           │
│ ─────────────────────────── │
│  水を張った水田・苗の列（ぼけ）          │
│                                    │
│        🐸 ← 目にピント                │
│      ＝＝畦の土・草＝＝  （下 1/3）       │
└──────────────────────────────┘
   カエルは左の3分割線、頭は右（田んぼ側）を向く
```

### 2.3 第1候補が無いときの順位

| 順位 | 写真 | 良い点 | 注意点 |
|---|---|---|---|
| 2 | **水路や畦の構造物とカエル**（コンクリート水路の壁、魚道、排水路の縁、暗渠の出口などにいるカエル） | 「整備の構造がカエルにどう効くか」という講演の核心が写る。技術者の目を最も引く | 水路に落ちて上がれないカエルなど、整備を責める印象が強すぎる写真は避ける。中立か、うまくいっている例がよい |
| 3 | **本州と北海道の2枚を左右に並べる**（左：本州の田んぼのダルマガエル、右：北海道の大区画水田のカエル） | 副題「本州と北海道」がそのまま絵になる。本を読んだ人にも伝わる | 1枚あたりが縦長 約8×12 cm になるので、それぞれ縦構図で撮った写真が要る。2枚の色味と明るさをそろえる |
| 4 | **カエルの顔のアップ**（目の高さ、背景はぼけた水面や緑） | 目を引く力が最も強い。暗いところでもピントが合わせやすい | 田んぼが写らないので題とのつながりが弱い。他に無いときの予備 |

### 2.4 避けたい写真

| 写真 | 理由 |
|---|---|
| **手のひらにカエルを乗せた写真**（現在のパンフレット案の写真） | 画面の大部分が手で、田んぼが写っていない。生きものの保全がテーマの講演で「捕まえて持つ」絵が主役になるのも避けたい。また、写っているのは本州のトノサマガエル類（ダルマガエル類）と思われ、北海道の聴衆には「北海道の話」に見えにくい。本の紹介として講演スライドで使うのはよい |
| 抱接（交尾）中のペアのアップ | 生態としては面白いが、チラシでは何の場面か伝わりにくい |
| 卵塊・オタマジャクシの大量に写ったアップ | 苦手な人がいる。チラシの第一印象で損をする |
| ウシガエルなど外来種が主役の写真 | 外来種の話が講演の中心でない限り、メッセージがずれる |
| 死んだカエル、道路で轢かれたカエル | 問題提起としては強いが、チラシには重すぎる |
| 夜にフラッシュで撮った写真 | 背景が真っ黒になり、白黒印刷で何も分からなくなる |
| 学生・農家の顔がはっきり分かる写真 | 掲載の許可が要る。人を入れるなら後ろ姿か、顔が分からない距離で |

### 2.5 印刷に耐えるかの確認（選ぶときに必ず見る）

1. **白黒にしても分かるか**：チラシは事務局が白黒で刷る可能性がある。写真を白黒に変えて、カエルが背景から浮いて見えるか確かめる。緑のアマガエルが緑の稲の上にいる写真は、白黒にすると溶けて見えなくなりやすい。カエルと背景の **明るさが違う**（茶色の土の上の緑のカエル、明るい水面の前の暗いカエル など）ものを選ぶ。
2. **画素数**：16 cm 幅を 300 dpi で刷るには横 約1900画素が要る。最低でも横 1600画素（4:3 なら 1600×1200）以上。スマートフォンの写真でも、切り抜きすぎなければ足りる。
3. **端に大事なものを置かない**：写真枠の外周は枠線と重なるので、カエルの足先などが端で切れないようにする。
4. **出典の表記**：講師が撮った写真なら「写真：講師撮影（撮影地・季節）」とキャプションを入れる。例「水田の畦にいるニホンアマガエル（北海道、7月）」。大学の広報ページなど他所の写真を使う場合は、掲載元に転載の可否を確認する。

### 2.6 候補を選ぶときの採点表

手持ちの写真を何枚か並べて、各項目 0〜2 点で付けると、迷ったときに決めやすい。合計 9 点以上なら合格。

| 項目 | 2点 | 1点 | 0点 |
|---|---|---|---|
| カエルと田んぼが両方写っている | 両方はっきり | 田んぼがかすかに分かる | カエルだけ／田んぼだけ |
| 北海道の写真か | 北海道の水田 | 撮影地不明 | 本州の写真 |
| カエルの目にピントが合っている | 合っている | やや甘い | ぼけている |
| カメラの高さ | カエルの目の高さ | 斜め上から | 真上から |
| カエルの向き | 空いた側を向く | 横向き | 端の外を向く |
| 白黒で見分けられる | はっきり | なんとか | 溶ける |
| 横長 4:3 に切れる | そのまま切れる | カエルが端に寄る | 縦長で切れない |

## 3. 次にすること

1. 上の第1候補に当てはまる写真を手持ちから探す（無ければ第2〜4候補の順に）。
2. 選んだ写真を白黒に変えて見え方を確認する。
3. 主催者に、決定案のタイトルと写真（撮影地・季節・種名のキャプション付き）を送る。開催案内の本文の差し替えも合わせて提案するかを決める。
