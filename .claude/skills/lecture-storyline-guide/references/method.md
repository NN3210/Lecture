# 筋を見つける方法と、第3回での実際の答え

講師用解説の価値は「筋」の一文で決まる。HTML を書き始める前にこのファイルの問いに答える。

## 1. 筋の一文（主張＋理由＋帰結）

よくない形: 「座標・ジオイド・測地系・投影・座標計算を学ぶ」（項目の列挙）。
よい形: 「X は Y で決まる。Z だから W になる。」

| 問い | 第3回「測量の座標」での答え |
| --- | --- |
| この分野の機器・手法が**直接**できることは何か | 距離と角を測ること（GNSS も衛星までの距離） |
| それだけで決まらないものは何か | 位置（置き場所）。形は決まるが置き場所は決まらない |
| 決まらない部分を何が決めるか | 人の約束（基準点、座標参照系） |
| 約束が単純で済まない理由は何か | 地球が曲がり（投影）、でこぼこで（ジオイド）、動く（元期） |
| したがってこの回は何をしているか | 約束の階層を地球から杭まで一度通して歩く |

他の回で同じ問いを立てるときの例:

- 誤差論（第2回）: 「観測値は必ずばらつく。ばらつきは消せないが、性質ごとに扱いが違う（過失は除く、定誤差は補正、偶然誤差は統計）。だから測量は『1 つの値』ではなく『最確値と、その信頼度』を報告する。」
- 水準測量: 「高さは重力が決める。レベルは気泡で重力を見ているから、積み上げた高さはジオイドからの高さになる。往復・環閉合で誤差を見つけ、距離に比例して配る。」
- トラバース: 「角と距離で形を決め、既知点で置く。閉じた図形は閉じるはずなので、閉じない分が誤差。誤差を配って整合させる。」

## 2. 繰り返す言葉（2〜3 語）

授業中に何度も口にする語。個々の数値・制度・式が全部この語に帰着するか確かめる。
第3回: 「約束」「形と置き場所」「幾何と物理」。
450 m（約束の違い）、29 m（幾何と物理の差）、0.9999（ひずみを管理する約束）、X が北（約束）がすべて帰着した。

## 3. 対比（2〜4 個）

内容と試験の誤文が、どの対比の取り違えかで分類できるものを選ぶ。
第3回: 形／置き場所、幾何／物理、曲面／平面。
誤文「GNSS で直接求まるのは標高」→ 幾何と物理の取り違え。
誤文「X 軸は原点で子午線に直交」→ 平面の約束（定義）の取り違え。

## 4. 地図（板書に残す 1 枚）

形式は内容で選ぶ。

| 形式 | 向く内容 | 例 |
| --- | --- | --- |
| 梯子・階層 | 抽象 → 具体、地球 → 現場 | 第3回: 地球 → 測地系 → 地心直交 → 地理＋標高 → 投影 → 現場（6 段） |
| 流れ図 | 観測 → 計算 → 成果 | トラバース: 観測角 → 方向角 → 緯距経距 → 閉合差 → 配分 → 座標 |
| 時間軸 | 歴史、作業工程 | 測地系の変遷、公共測量の工程 |
| 2×2 の表 | 対比が 2 つ直交する | 誤差の種類 × 対処 |

各節がこの地図のどこに当たるか、GNSS/TS などの機器がこの地図をどう動くかを言えること。

## 5. 節の順序の理由

節ごとに「なぜここにあるか」を一文で。言えない節が構成の弱点。
第3回で言えなかった点: 3-3 の後半（制度 43〜45）が投影の後に来る理由。→ 第 8 節で「A・B・A の混在」として指摘し、分割案を書いた。

## 6. 橋渡しの言葉

節の最初の 30 秒で言う台詞。前の節の結論を一文で受け、次の節の問いを一文で立てる。
型: 「ここまでで○○が決まった。では△△はどうか。できない／足りない。なぜか。□□だから。」
第3回の例（3-2 → 3-3）: 「高さの 0 は決まりました。次は水平の約束、つまり『どの地球の形を、どう置くか』。古い地図と新しい地図で同じ杭が 450 m ずれる話から入ります。」

## 7. 背景の引き出し

スライドに書かないが、質問が出たとき・一言添えたいときに使う知識。
出す基準: その知識があると「なぜ」が一段深く言えるもの。
第3回で効いたもの: 等角写像だと 1 点の縮尺が方向によらず一つの数で済む（だから縮尺係数が一つの数）、レベルの気泡は重力を見ている（だから水準測量はジオイドからの高さ）、鉛直線偏差（だから測量法は「地理学的経緯度」と書く）、X が北なのはガウス・クリューゲルで x を中央子午線に取る流儀。

## 8. 弱点を正直に書く

講師が「教えにくい」と感じた原因を構成の側から特定する。よくある原因:

- 節末の「試験で問われる型」や「確認」で物語が止まり、次の節に橋渡しの枚がない
- 一つの節に性質の違う話（概念と制度、原理と計算）が混在する
- 全体図（地図）が 1 回しか出ない、または無い
- 節の見出しが項目名（固有名詞）で、思想の語（約束、不変、補正）が消えている
- 後から追加した枚（試験対応など）が思想の流れを優先していない

改訂案は効果の大きい順に 3 点、枚数の増減も書く。
