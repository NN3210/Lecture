# 段階コード表：トラバース測量（測量学 第 5 回「トラバース測量 I」用の下書き）

下書き（2026-10-22）。段階 1 で集めた資料を 10 件ほど開いてから直し、圧縮を始めたら変えない。
授業計画 `lecture_plan_13.md` 第 5 回の到達目標：閉合トラバースの測角誤差を調整し、方向角と緯距・経距を計算でき、2 点の座標から距離と方向角を逆計算できる。
第 6 回（トラバース II：閉合差・調整・座標計算・面積）の話題も資料には続けて出るので、コードを置いて順序を見る（この回では扱わない）。

| コード | 内容 |
| --- | --- |
| WHY | なぜトラバースか（基準点から新点を増やす、座標を付ける目的、現場の例、三角測量との違い） |
| TYPES | トラバースの種類（閉合・結合・開放・多角網）、用途、精度と点検可否の違い |
| SELECT | 選点・踏査（見通し、辺長の均等、辺数、点の保護・標識、既知点の確認） |
| INSTR | 器械と観測法（トータルステーション・トランシット、対回観測、正反、距離の測り方、野帳） |
| ANGLE | 内角・交角・偏角の観測と測角誤差（内角の和 (n−2)×180°、角の閉合差、許容範囲） |
| ADJUST | 測角誤差の配分（等配分、辺長や観測条件に応じた配分、調整後の角） |
| AZIMUTH | 方向角・方位角の計算（交角法・偏角法、前視方向角 = 後視方向角 + 角 ± 180°、0〜360° の処理、磁北・真北・座標北） |
| LATDEP | 緯距・経距（ΔX = s cos θ、ΔY = s sin θ、符号と象限、合計） |
| CLOSURE | 閉合差・閉合比（緯距経距の和、閉合比の計算、精度の判定、許容値） |
| COMP | 緯距経距の調整（コンパス法則・トランシット法則、調整量の配分） |
| COORD | 座標計算（調整後の緯距経距から X・Y を累積、座標一覧、成果表） |
| INVERSE | 座標の逆計算（2 点の座標から距離と方向角、象限判定、atan2） |
| AREA | 面積計算（座標法・倍横距法） |
| ERR | 誤差論・精度（器械誤差・個人誤差、過失の見つけ方、角と距離の精度のつり合い） |
| EX | 演習・例題・クイズ・まとめ・次回予告（数値例を最後まで通すものを含む） |
| OTHER | 上記に入らないもの（括弧で 5 字以内の補足を付ける） |

導入型：問い／例／歴史／定義／目次／不明。

## 到達目標との対応（第 5 回で扱うコード）

| 到達目標の項目 | コード |
| --- | --- |
| トラバースの種類と用途、選点 | TYPES、SELECT |
| 測角誤差の許容と等配分、内角の和 | ANGLE、ADJUST |
| 方向角の計算（交角法・偏角法） | AZIMUTH |
| 緯距・経距 | LATDEP |
| 座標の逆計算（距離、方向角の象限判定） | INVERSE |
| （第 6 回）閉合差・調整・座標・面積 | CLOSURE、COMP、COORD、AREA |

## 直すときの目安

- 資料の 1/3 以上が「INSTR」を最初に置くなら、INSTR を「観測（OBS）」と「器械の据え付け」に分けるか検討する。
- 「AZIMUTH」が長い資料が多い（交角法と偏角法を別々に教える）なら AZ_INT・AZ_DEF に分けると順序対が見える。
- OTHER が 25% を超えたら、OTHER の括弧の補足を集計して新コードにする。
