# 点検の道具と Sonnet の PNG 点検プロンプト（段階 4）

## 1. 機械で：ヘッダーとページ番号（PNG を見る前に）

```
python -I $SK/lecture-deck-build/scripts/check_headers.py "<pptx>" --header-prefix "測量学 第N回"
```

枚ごとに `NNN | ヘッダー文字列 | ページ番号 | (HIDDEN)` を出し、最後に次を数える：非表示の枚、ページ番号が位置と違う枚、章番号が前の枚より戻る枚、ヘッダーの無い枚（旧世代の枚。第 3 回では 48 枚あり、直さなかった）。
章番号の戻りは「章を移した枚に `header=` を書き忘れた」合図。

## 2. 統括が目で見る枚（10 枚まで）

新規枚すべて、ヘッダーを書き換えた枚、非表示から戻した枚、章の切れ目の 1〜2 枚、最終枚。`Read` で PNG を開く。見る点：カードの文字が枠に収まるか、帯が 1 行か、型紙と同じ配色か、ページ番号が `順 / 総数` か。

## 3. Sonnet に全枚を見させる（1 体。108 枚で約 3.5 分・約 9 万トークン）

```
あなたは講義スライドの校正係です。日本語で作業します。
<scratch>/png/ にある スライド1.PNG 〜 スライドNNN.PNG（NNN 枚、1280×720）を番号順に全部 Read で見て、
次の観点で問題のある枚だけを表にして <root>/確認画像/sonnet_点検.md に書く。

観点：
1. 文字のはみ出し（枠の外に出ている、下端で切れている）
2. 文字や図の重なり（読めない所がある）
3. 空の枠（見出しだけで本文が無い、カードが空）
4. ページ番号が「位置 / NNN」と一致しない、または番号が無い
5. ヘッダー（左上の「測量学 第N回 / 章番号 | 章名」）の章番号が前の枚より戻る、またはヘッダーが無い
6. 見た目が前後の枚と明らかに違う（配色・フォント・レイアウト）

表の形：
| 枚 | 観点 | 何が起きているか（1 行） |

問題の無い枚は書かない。直し方は書かない（判断は統括がする）。個人名は書かない。
最後の返答は「問題の枚数」と「書いたファイルのパス」の 2 行だけ。
```

## 4. 指摘の判断（第 3 回の例）

| 指摘 | 判断 | 対応 |
| --- | --- | --- |
| 新規枚のカード 1 が枠の下にあふれる、帯が 2 行 | 直す | `04_新規枚.md` の文を短くして組み直し |
| 13 枚目の章ヘッダーが 02 のまま 01 章の中にある | 直す | 構成案の備考に `header=…01…` を足して組み直し |
| 旧世代の 10 枚の脚注が「1」「14」など古い番号 | 直す | `--renumber` が下端 15% の数字だけの枠も書き換える（今の版は対応済み） |
| 旧世代の 48 枚にヘッダーが無い | 直さない | 改 N と同じ見た目。直すなら元デッキ側で |
| 表の最下行が帯に少し重なる（元デッキの枚そのもの） | 直さない | 読める範囲。直すなら元デッキの表の高さを縮める |
| 小さい画像が大きい図に重なる（アニメーション前提の作り） | 直さない | 元デッキのまま |

「直さない」ものは手順書か worklog に理由付きで残す。次の改訂で元デッキ側を直すときの一覧になる。
