# 構成案・新規枚の書式（`build_pptx.py` が読む規則）

## 1. `04_構成案.md`

```
# 04 改N+1 構成案（<出力ファイル名>.pptx の枚順）

作成日：…。根拠：03 §4 の飛び石チェック表、改N_構成診断 §3〜§5。新規枚の中身：04_新規枚.md。

## 1. 方針（03 §5 の骨格）
- 骨格は多数派の「A 通し型」（WHY → … → SCALE）に終盤で「D 計算型」（AXIS → CALC → EX）を接続する。
- 章立て（START／01〜06／TRY／GOAL）は改 N のまま使う。
- 非表示のうち 14（今日のゴール）と 37（数値例）は表示に戻す。残りは入れない。
- 重複は 1 つに絞る（…）。新規 4 枚を飛び石の位置に入れる。

## 2. 枚順

| 順 | 元 | 題 | 備考 |
| --- | --- | --- | --- |
| 1 | k1:1 | 表紙 | START |
| 6 | k1:14 | 今日のゴール | 非表示→表示。WHY を冒頭に（03 §4.1、診断 §3-6） |
| 13 | k1:28 | 地球はほんの少し横長 | 章を移す。header=測量学 第3回  /  01  \|  場所を伝える |
| 14 | new:latlon | 緯度・経度・楕円体高はどう決める？ | 新規。LATLON が無かった（03 §4.2） |

## 3. 改 N から外した枚（NN 枚）

| 枚 | 理由 |
| --- | --- |
| 6〜13 | 小テスト（非表示。授業で話さない） |
```

規則：

- `元` は `<接頭辞>:NN`（元デッキの NN 枚目。1 始まり、非表示を含む並び順。接頭辞は `k1`・`k2`・`src` など英小文字で自由）か `new:ID`（新規枚。ID は英数字・`_`・`-`）。
- 同じ枚を 2 回使えない（止まる）。元デッキに無い番号も止まる。
- 備考の `header=…` は、その枚の「ヘッダー接頭辞で始まる段落」（例 `測量学 第3回  /  01  |  場所を伝える`）を書き換える。表の中なので縦棒は `\|`。章を移した枚だけに書く。
- 備考に根拠（03 の節番号、診断の項目番号、段階コード）を書いておくと、後で「なぜこの位置か」を説明できる。
- `--renumber` でページ番号は `順 / 総数` に振り直される（`NN / 81` 形の段落と、下端 15% にある数字だけの脚注）。番号の無い枚はそのまま。

## 2. `04_新規枚.md`

```
# 04 新規枚（改N+1 で追加する 4 枚の中身）

型紙は改 N の 25 枚目（3 枚カード型）。cardN: 見出し | 本文 1 行目 / 2 行目。

## new:latlon
- template: 25
- header: 測量学 第3回  /  01  |  場所を伝える
- title: 緯度・経度は、楕円体の上でどう決める？
- subtitle: 楕円体を決めると、その上で「角度の住所」が定義できる。
- card1: 緯度 φ | 赤道面と、その点を通る楕円体の法線がなす角 / 北緯・南緯 0〜90°
- card2: 経度 λ | 本初子午線（グリニッジ）から東西へ測った角 / 東経・西経 0〜180°
- card3: 楕円体高 h | 楕円体面から法線に沿って測った高さ / GNSS が直接出すのは、この h
- takeaway: 緯度・経度は角度。経度 1° は赤道で約 111 km、帯広では約 82 km と、場所で長さが変わる。
- notes: （発表者ノート。この枚を新設した根拠＝資料の順序対の数字も 1 文入れておく）

## new:summary_bullets
- template: 25
- header: 測量学 第3回  /  02  |  高さをそろえる
- title: ここまでの約束
- bullets: 標高はジオイドから / 楕円体高は楕円体から / 差がジオイド高 N
- takeaway: h = H + N
```

規則：

- `template`：型紙にする元デッキの枚番号。型紙は「文字だけで図の無い枚」を選ぶ（複製は図形と文字枠だけを写し、画像の関係は写さない）。
- `cardN`：`見出し | 本文`。本文の `/` で改行。**1 カードの本文は全角 40 字前後まで**（それより長いと枠の下にはみ出す。第 3 回で 2 枚あふれた）。
- `bullets`：カードを消して 1 つの枠に箇条書き（`/` 区切り）。`cardN` と併用しない。
- `takeaway`：帯の 1 文。**全角 45 字まで**（2 行になると下端にかかる）。
- `subtitle` を省くと空になる。`notes` は発表者ノートに入る。
- 文字の書式は型紙の最初の run をそのまま使うので、太字や色は型紙に合わせて決まる。

## 3. 型紙の部品名（`--shape-map`）

既定は第 3 回の視覚版「3 枚カード型」（25 枚目）の部品名：

```json
{"header": "TextBox 2", "title": "TextBox 3", "subtitle": "TextBox 4", "page": "TextBox 5",
 "cards": [["TextBox 9", "TextBox 10"], ["TextBox 14", "TextBox 15"], ["TextBox 19", "TextBox 20"]],
 "card_shapes": ["Rounded Rectangle 6", "Rounded Rectangle 7", "TextBox 8", "TextBox 9", "TextBox 10",
                 "Rounded Rectangle 11", "Rounded Rectangle 12", "TextBox 13", "TextBox 14", "TextBox 15",
                 "Rounded Rectangle 16", "Rounded Rectangle 17", "TextBox 18", "TextBox 19", "TextBox 20"],
 "takeaway": "TextBox 23"}
```

別のデッキ・別の型紙を使うときは `build_pptx.py <deck> --list-shapes NN` で部品名と文字を出し、同じ形の JSON を書いて `--shape-map map.json` で渡す。`card_shapes` は `bullets` のときに消す部品（カードの枠・番号札・見出し・本文。本文 1 つだけ残して広げる）。
