# 資料収集の共通指示（サブエージェント用）

目的：{{SUBJECT}}の講義のうち「{{TOPIC}}」の回（{{SUBTOPICS}}）に相当する、世界中の講義スライド・講義ノート・YouTube 動画を集める。
隣接範囲（{{ADJACENT}}）まで通して教えている資料も対象にする（どこで区切るのが自然かを知る材料になる）。
集めた一覧は、後段で「各資料がどの順番で何を教えているか」を抽出するために使う。

## 対象とする資料

- 大学・高専・専門学校・MOOC（NPTEL、Coursera、edX、OpenCourseWare など）の講義スライド（pdf / pptx / html）、講義ノート、講義動画。
- 公的機関の教育向け解説ページ・動画（{{INSTITUTIONS}}）。
- YouTube の講義動画・解説動画（再生リストは代表 1 本をリストにし、備考に再生リストであることと本数を書く）。
- 対象外：試験対策の問題だけのページ、ソフトの操作説明だけのページ、ブログの短文、商品ページ、ログインが要る LMS のページ。

## 必須の条件

- 1 件ごとに URL を WebSearch の結果からそのまま記録する。**URL を推測して作らない**（ドメインと講義名から「ありそうな URL」を組み立てない）。
- 可能なら各件の URL を WebFetch で 1 回開き、実在と内容（{{TOPIC}}の講義であること）を確認する。確認できなかったものは備考に「未確認」と書く。
- PDF が直接開ける URL を優先する。講義一覧ページしか見つからないときは、そのページの URL を書き、備考に「一覧ページ」と書く。
- 個人名は書かない（公開リポジトリのため）。作成者は機関名・チャンネル名・講義名で表す。
- 1 件 1 行の Markdown 表にし、列は次のとおり（10 列。セル内に `|` を書かない）。

| No. | 種別 | タイトル | 作成者（機関・チャンネル） | 言語 | 年 | URL | 扱う話題（順に、「→」でつなぐ） | 長さ | 備考 |

- 種別：スライド / 講義ノート / 動画 / 動画(再生リスト) / 教科書章 / 解説ページ
- 言語：日本語 / 英語 / ドイツ語 … のように日本語で書く（en、ja などの略号は使わない）。
- 扱う話題：ページを読んで分かった範囲で、資料の中で登場する順に書く（例：{{SUBTOPICS_EXAMPLE}}）。分からなければ「要確認」と書く。
- 長さ：スライド枚数、ページ数、動画の分数など。
- 年：分かれば西暦。不明なら「不明」。

## 出力

- 指定されたファイルに Markdown で保存する（表の前に 3 行以内で、どんな検索語で探したかを書く）。
- 件数は指示された数を目標にする。重複（同じ URL）は除く。
- 最後に、集めた件数と、確認できなかった件数を 2 行で報告する。一覧の本文は返答に貼らない。
