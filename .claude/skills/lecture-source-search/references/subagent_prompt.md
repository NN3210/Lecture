# サブエージェントの分担と起動プロンプト

`init_collect_dir.py` がこの雛形を埋めて `<root>/collect/_起動プロンプト.md` に 4 本書く。統括はそれを 1 つのメッセージで 4 つの Agent 呼び出し（subagent_type: general-purpose、model: sonnet）として送る。

## 分担

| 体 | LETTER | NAME | SCOPE | N |
| --- | --- | --- | --- | --- |
| A | A | 英語スライド | 英語の大学・MOOC・公的機関の講義スライド・講義ノート・教科書章（pdf / pptx / html）。動画は含めない | 28 |
| B | B | 英語動画 | 英語の YouTube 講義動画・解説動画（大学の公式チャンネル、MOOC、教育チャンネル）。再生リストは代表 1 本 | 28 |
| C | C | 日本語 | 日本語の資料。大学・高専の講義ページ・スライド・ノート、公的機関の解説ページ、YouTube の講義・解説動画。資格試験対策の動画は講義の形になっているものだけ | 28 |
| D | D | 他言語 | 英語・日本語以外の言語の資料（スライド・ノート・動画）。1 言語 6 件以内で、ドイツ語・スペイン語・フランス語・ポルトガル語・インドネシア語・ロシア語・ウクライナ語・トルコ語・中国語・韓国語などから幅広く | 24 |

## 起動プロンプト（1 体分）

```
あなたは{{SUBJECT}}の講義「{{TOPIC}}」の資料収集の担当 {{LETTER}} です。日本語で作業してください。

1. まず `{{ROOT}}/collect/_収集指示.md` を読み、その条件（URL を推測しない、WebFetch で 1 回開く、個人名を書かない、10 列の表）を守ってください。
2. 担当範囲：{{SCOPE}}。目標 {{N}} 件。
3. 検索は WebSearch（mode は standard。結果が薄いときだけ extended）で、検索語を言い換えながら（例：{{SEARCH_TERMS}}）10 回以上行ってください。見つけた URL は WebFetch で 1 回開いて、実在と内容を確かめてください。開けなかったものは備考に「未確認」と書きます。
4. 結果を `{{ROOT}}/collect/資料収集_{{LETTER}}_{{NAME}}.md` に保存してください（表の前に、使った検索語を 3 行以内で）。
5. 返答は「集めた件数」「未確認の件数」の 2 行だけにしてください。一覧の本文は返答に貼らないでください。

git 操作はしないでください。書いてよいのは上のファイル 1 つだけです。
```
