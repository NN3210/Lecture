### §1 の読み取り

- 本文を確認できた 5 教材（NRCan 1.4、NPTEL、JAXA、高知工科大、NASA Earthdata）で共通するのは「電磁波 = 波 → 波長帯の名前 → 太陽（反射）と地球（放射）→ 大気 → 地物との相互作用」の流れ。
- CCRS と JAXA は先に「センシングとは何か、何を測るか」を置き、式は少ない。NPTEL と高知工科大は式を全部出す。NASA Earthdata は式を出さない。
- CCRS は 1.2 のスペクトルを 1.3 大気より先に置く。大気を後ろに回す点は昨年度スライド（太陽スペクトル大気外 → 地上）と近いが、昨年度は放射の法則を先に置いている点が異なる。

### §4 の読み取り

- 本文を確認できた範囲では、入門レベルは次のいずれかで済ませている。(a) 式なし（NASA Earthdata、JAXA）、(b) 数値だけ（太陽 0.5 µm、地球 10 µm）で「2 つの山」を作る（高知工科大）、(c) 式は出すが導出なし（NPTEL）。
- 共通して残すのは、「太陽は約 6000 K で可視にピーク」「地球は約 300 K で熱赤外にピーク」「熱いものほど短い波長」の 3 点。プランクの式そのものを提示する教材は今回の確認範囲に無かった。
- 昨年度は 3 法則すべてを式付きで並べている。確認範囲の入門教材と比べると多い。

## §5 推奨する段階（梯子）案

注: 各段の「なぜこの順か」は、出典が明示した理由と、私の推測を分けて書く。本調査で、各教材が「なぜ次へ進むか」を明示している箇所は多くなかった。出典が明示した理由と書けるのは、教材の目次・順序そのものが示す並びと、教材が自ら述べた説明に限る。

| 段 | 内容（案） | なぜこの順か：出典が明示した理由 | なぜこの順か：私の推測 |
|---|---|---|---|
| 0 | 目で見ることも RS（太陽光 → 物 → 目 → 脳）、衛星は写真ではなく各画素の測定値 | NPTEL M1L2 が「目で見る = 自然の RS」で導入。ESA Eduspace も 3 要素から導入（どちらも本文確認） | 衛星 = 写真という誤解を最初に潰す。式を出す前に全体像を置く |
| 1 | 光は波で、色 = 波長。プリズムと虹。目に見えるのは 0.4〜0.7 µm だけ | NOAA Lesson 1 は虹・プリズムから入る。JAXA 基礎知識は「可視光は電磁波のほんの一部」から入る（本文確認） | 既知（虹）から未知（見えない光）へ。水面波のたとえは補助で十分 |
| 2 | 見えない光が確かにある: スマホでリモコンの赤外、紫外線ビーズ。スペクトルの全体図（電波・マイクロ波・赤外・可視・紫外） | NOAA は「見えないがエネルギーがある」を実験で示す。IOP Spark もスマホデモで同様（検索要約） | 体験を波長の話より前に置くと、赤外 = 熱の誤解より前に「赤外は光の仲間」を入れられる。教室で 1〜2 分 |
| 3 | 波長・周波数・エネルギー: c = λf は「波長が短いほど揺れが速い」と図で。E = hf は「短い波長ほど 1 粒が大きい」と言葉で | NPTEL M1L2 が c = λf、Q = hf の順で提示（本文確認）。CCRS 1.1 も電磁放射 → 波長・周波数の順 | 式より先に比例・反比例の向きだけを確認。計算させない（Penn State の「概念中心」と同じ立場、概要のみ） |
| 4 | 光の出どころ 2 種類: 太陽光を「返す」（反射）と、物が自分で「出す」（放射）。夜の景色やサーモ画像と日中の景色を対比 | JAXA 基礎知識と高知工科大が「可視・近赤外 = 反射、熱赤外 = 放射」を先に述べて波長帯を分ける（本文確認） | 反射と放射の混同を、法則の前に潰す。熱赤外と近赤外を分ける準備にもなる |
| 5 | 放射の法則は 2 つの結論だけ: 「熱いほど強く、短い波長で光る」。太陽は約 6000 K で 0.5 µm、地球は約 300 K で 10 µm。ステファン・ボルツマンは T⁴ の方向だけ | 高知工科大が数値だけで 2 つの山を作る。NPTEL は式付き。NASA Earthdata と JAXA は式なし（本文確認） | 日常は「焚き火・電熱線が赤くなり、さらに熱いと白い」で方向を示す（推測。この例を使う入門教材は未確認）。プランクの式は出さず曲線の図で見せる。黒体 = 理想的な吸収体という言葉は 1 行 |
| 6 | 大気: 通り抜ける波長（大気の窓）と、太陽スペクトル（大気の外と地上）の比較。可視・近赤外・熱赤外・マイクロ波の窓 | CCRS は 1.2 スペクトルの後、1.3 で大気（目次）。NPTEL も太陽・地球放射の後に大気の窓（本文確認） | 放射が分かった後に出す方が、なぜ太陽のグラフが地上で凹むかを読める（推測） |
| 7 | 物と光の出会い: 吸収・透過・反射。鏡面と拡散。色は「反射された波長」。水、土 | NRCan 1.4 が吸収・透過・反射 → 鏡と粗い面 → 葉 → 水の順（本文確認） | 葉の話に入る前に、反射 = 返すものという型を 1 度作る |
| 8 | 葉: 緑に見える理由（クロロフィルが青・赤を吸収）→ 近赤外を葉の内部（海綿状組織）が強く散乱 → 反射スペクトル（レッドエッジ） | NRCan 1.4 は葉の色と近赤外の拡散反射を述べる。ITC Twente は「葉の光学 → 近赤外の挙動 → レッドエッジ」の順（本文確認）。断面図の使用は NRCan では確認できず | 断面図に光線を 2 本（赤・近赤外）描き、各層で何が起きるかで 1 枚にする案（推測）。目の感度が 0.7 µm 以上へずれたらの思考実験（高知工科大）で「見えない近赤外」を体験させる |
| 9 | NDVI: 赤と近赤外の差 → 分母を足して割る（明るさが違っても同じ値、-1〜1）→ 値の読み方 | ITC Twente は「レッドエッジ → NDVI 計算 → しきい値・応用」の順。JAXA 基礎知識も物理量プロダクトの 1 つとして NDVI を後段に置く（本文確認）。分母の意味の説明は streambatch と KSRE の検索要約 | 差だけで見せ、「晴れの日と曇りの日で同じ畑の差が変わる」例で分母の必要を引き出す（推測）。「ある程度の正規化」に留める（KSRE） |

### 昨年度スライドとの対応と提案

- 昨年度の順は「電磁波（水面波、c = fλ、E = hf）→ 放射（ステファン・ボルツマン）→ プランク → ウィーン → 太陽スペクトル → 分光反射 2 枚」。上の梯子との違いは次の 4 点（いずれも案、根拠は表の通り）。
  1. 段 0〜2（導入と体験）を前に置く。
  2. 段 4（反射と放射の区別）を放射の法則の前に置く。
  3. 段 5 は 3 法則を式で並べず、2 つの結論と数値（0.5 µm、10 µm）にまとめる。確認範囲の入門教材（NASA Earthdata、JAXA、高知工科大）はこれに近い。
  4. 段 7〜8 で、反射の型 → 葉の断面 → 反射スペクトルとつなげ、段 9 で NDVI につなぐ。昨年度は 2 枚だけ。
- 式をどこまで残すかは講師判断。残すなら c = λf、E = hf、ウィーンの λm = 2898/T 程度を「向きの確認」として使い、計算問題にしない案。
- 未確認で残る点: 日本の高校物理の電磁波単元の実際の順番、宙畑・RESTEC・日本リモートセンシング学会の教材、学生の誤解を直接調べた RS 教育の研究。必要なら追加調査する。
