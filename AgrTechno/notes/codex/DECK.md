# 電磁波からNDVIまでの図版・段階設計ルール

2026-10-22。対象は13段の設計書と13点の図版。既存のslides.mdを唯一のスライド原稿として維持し、本ファイルは原稿の代替にしない。

- DENSITY 3 / MOTION 1 / VARIANCE 5。1枚1主張、根拠は1つの主図。詳細は発表者ノートへ置く。
- 固有の道標は「光の行き先を追う矢印」。太陽から出る→大気を通る→葉で吸収・散乱→センサで測る→指標にする、を通して維持する。
- 構成は経路図、波の比較、物理曲線、葉の断面、スペクトル、棒グラフを交替させる。式の連続表示を避ける。
- 指定パレット：アイボリー#FAF9F5、紺#1F4E79、青緑#13877B、橙#BD512B、灰#8A8A8A。虹色は可視帯の説明にのみ使う。
- 図版は8×4.5 inch、200 dpi、1600×900 px。軸文字は14 pt以上。日本語フォントはYu Gothic→Meiryo→MS Gothic。図内に図タイトルは置かない。
- 本文の見出しは結論を述べる文にし、箇条書きの羅列・装飾カード・3Dグラフ・汎用イラストは用いない。
- 理論値、模式値、一般仕様、計画、未確認を区別する。図の模式深さを測定値として使わない。
- 全図で画素数、フォント字形、画像外の文字、目視による重なりを確認する。
