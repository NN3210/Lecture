# MakePaddy 作業ルール

- このプロジェクトの作業対象は `Lecture/MakePaddy/` です。コマンドは原則としてこのディレクトリを作業ディレクトリにして実行します。
- 成果物・中間ファイルはすべて `MakePaddy/` 以下に保存してください。
- `Surveying/` など、他のプロジェクトのファイルは、ユーザーから指定がない限り変更しないでください。
- 日本語で記述し、作業内容は `notes/worklog.md` に日付付きで追記してください。
- Git 操作には親の Lecture リポジトリを使います。独立した Git リポジトリやサブモジュールは作成しません。
- 公開情報・ファイルサイズ・commit / push の扱いは、親の `AGENTS.md` に従ってください。
