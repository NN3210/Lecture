# MakePaddy

Lecture リポジトリ内のプロジェクト用フォルダです。今回のプロジェクトは、この `MakePaddy/` を対象とします。
Git の履歴は Lecture リポジトリで管理します。

## 進め方

1. リポジトリ直下と、このフォルダの `AGENTS.md` を確認する。
2. 成果物・中間ファイルは `MakePaddy/` 以下に保存する。
3. 作業内容を `notes/worklog.md` に追記し、Lecture の `main` に commit / push する。

プロジェクトの具体的な目的や成果物は、今後の指示に合わせて追記します。
